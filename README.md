## 스카이 체이서

0.9.2는 2·3스테이지를 승인된 Ah/Oh 무언 코러스 록 BGM으로 교체했습니다. 게임에서는 반복 구간을 겹쳐 연결하고, 감상 화면에서는 마지막이 서서히 줄어듭니다.

0.9.1은 스테이지와 최종 보스 음악이 끊김 없이 이어지도록 정리하고, 이야기를 화면 전체의 루미·보스 컷인으로 바꿨습니다. 짧은 전환 음악과 중간 보스 전용곡을 제외한 [BGM 여덟 곡](https://gomoorae.github.io/My_web_games/games/sky-chaser/soundtrack.html?v=0.9.2)을 감상할 수 있습니다.

0.8.1은 3스테이지 후반 호위 편대를 늘리고 폭격기의 일반탄을 더 자주 발사합니다. 볼칸·이그니스의 공격 간격을 줄이고 폭발탄과 교차탄을 조합했습니다. 쉬움은 강화 폭을 줄이며 1·2스테이지와 기존 조작은 유지합니다.

**빼앗긴 바람** 이야기를 추가했습니다. 오프닝·스테이지별 장면·엔딩이 연결되고, 본 장면은 다음 출격에서 자동으로 건너뜁니다. 시작 화면의 이야기 메뉴에서 다시 보거나 자동 생략을 끌 수 있습니다. 연습 모드는 바로 출격합니다.

휴대폰에서는 같은 게임 링크가 모바일 조작으로 연결됩니다. 왼쪽 패드로 이동하고 오른쪽 버튼으로 차지샷·폭탄을 사용하며 기본 사격은 자동입니다. 감도 기본값은 1.1이고 정밀 이동 버튼은 없습니다. 감도·좌우 배치 설정과 시험판 기록을 이어받습니다. PC 키보드 조작과 기록은 유지합니다.

비행 배달부 루미가 빼앗긴 「바람의 심장」을 되찾기 위해 해풍의 항구, 뇌운의 협곡, 홍련의 조선소를 돌파하는 PC·모바일 세로 슈팅입니다. 스테이지별 전용 중간 보스와 변신 보스가 등장합니다. 세 스테이지를 연속 플레이하거나 2·3스테이지를 따로 연습할 수 있습니다.

**[스카이 체이서 플레이](https://gomoorae.github.io/My_web_games/games/sky-chaser/?v=0.9.2)** — 기본 사격 자동, 방향키/WASD 이동, Z 차지샷, X 천익 섬광, Shift 저속 이동, Esc 일시정지, F 전체화면. 현재 버전은 **0.9.2**입니다. 3스테이지에서는 폭발탄을 사격으로 요격하고 휘어지는 탄을 피해 화로거북 볼칸과 홍련룡 이그니스에 도전합니다. 기본 적의 진입 즉시 사격을 유지하고, 템페스트의 완전 원형탄과 이그니스의 분산 폭발탄을 강화했습니다.

P를 회수하면 파워 유지 시간이 25초로 갱신되고 놓치면 한 단계씩 내려갑니다. 격추 시 회복용 P가 나옵니다. PC 화면은 창 높이를 채우고, 기존 기록과 설정을 보존합니다. 상단 설정에서 PC 키보드 이동 감도를 50~120%로 조절할 수 있으며 기본값은 100%이며 Shift 정밀 이동은 선택한 일반 이동 속도의 70%입니다. 루미의 표시 크기와 피격 판정을 각각 10% 줄였습니다.

## 별냠

별 하나를 먹고 크게 도약해 다음 별로 건너가는 상승 게임입니다. 부스트를 얻으면 같은 하늘을 빠르게 올라가며, 좌우로 직접 별줄에 진입해 연속 수집합니다. 가깝고 높은 별, 중간 거리, 넓은 횡단을 섞은 경로를 올라가며, 푸른 하늘에서 10,000m 너머 별빛 우주까지 배경과 장애물이 바뀝니다. 높은 곳에서는 운석과 위성 잔해가 등장합니다.

**[별냠 플레이](https://gomoorae.github.io/My_web_games/games/star-munch/)** — A/D 또는 방향키로 이동, Space로 충전 도약, Esc로 일시정지, R로 다시 시작합니다. 휴대폰은 게임 화면의 왼쪽·오른쪽 절반을 눌러 이동하고, 양쪽을 함께 눌러 도약합니다. 하단 충전 표시를 눌러도 도약할 수 있습니다. 현재 버전은 **0.4.0**입니다. 작은 별은 도약 1칸, 큰 별은 3칸을 충전합니다.

`games/star-munch/`에 게임 소스, 그림, 빌드·검사 스크립트를 함께 보관합니다. 해당 폴더에서 `node scripts/build.cjs`를 실행하면 오프라인 실행용 단일 HTML을 만들 수 있습니다.

## 월하무쌍

자동으로 공격하는 무사를 움직여 6분을 버틴 뒤 마지막 고수를 쓰러뜨리는 무협 생존 게임입니다. 월하정원·청죽림·적염관의 서로 다른 지형, 권법·각법을 포함한 여덟 기본 무공과 아홉 합성 비기, 각 공격의 전용 그림 효과를 제공합니다. 모든 전장은 처음부터 선택할 수 있습니다.

**[PC 브라우저판](https://gomoorae.github.io/My_web_games/games/moonfall/)은 키보드 중심으로 조작합니다.** 이동은 WASD/방향키, 경공은 Space/우클릭, 절기는 E/좌클릭, 일시정지는 Esc, 합성 비급은 Tab입니다. 자세한 조작은 게임 아래 안내에서 볼 수 있습니다.

휴대폰에는 별도의 **[모바일 시험판](https://gomoorae.github.io/My_web_games/games/moonfall-mobile/)**을 제공합니다. 휴대폰을 가로로 돌려 플레이하며, 왼쪽 원형 패드로 이동하고 오른쪽 경공·절기 버튼과 메뉴를 터치합니다. 이동 패드는 입력한 방향으로 항상 최대 속도로 움직입니다.

PC 게임 페이지에서 **PC에서 시작**을 누르면 Godot 웹 빌드를 불러옵니다. **모바일판 시작**으로 모바일 시험판을 열 수도 있습니다. 첫 다운로드는 연결 속도에 따라 시간이 걸릴 수 있습니다. 화면이 멈추면 **다시 불러오기**를 이용하세요. 진행 중인 전투의 이어 하기는 지원하지 않습니다. 전체 화면 버튼으로 플레이 화면을 넓힐 수 있습니다.

- `games/moonfall/index.html`: 시작 화면, 전체 화면, 조작 안내
- `games/moonfall/game/`: Godot 웹 내보내기 파일. `index.html`과 함께 생성된 파일을 같은 위치에 유지합니다.

## 파일 구성

- `index.html`: 메인 페이지
- `styles.css`: 메인 페이지 디자인과 작은 화면 대응
- `app.js`: 게임 카드 표시
- `games.json`: 게임 목록과 표시 정보
- `games/`: 개별 게임
- `thumbs/`: 게임 썸네일
- `.nojekyll`: GitHub Pages 정적 파일 제공

## 로컬에서 열기

메인 페이지는 게임 목록을 불러오기 때문에 정적 서버가 필요합니다. 아래는 직접 실행할 때 사용할 수 있는 예시입니다.

```bash
python -m http.server 5500
```

브라우저에서 `http://localhost:5500`을 엽니다. 월하무쌍은 `http://localhost:5500/games/moonfall/`에서 실행하며, 파일을 더블클릭하는 방식으로는 실행할 수 없습니다. NEON TERRITORY 자체는 `games/neon_territory/index.html`을 더블클릭해도 플레이할 수 있습니다.

## 게임 추가

1. `games/새게임폴더/`에 게임 파일을 넣습니다.
2. `thumbs/`에 썸네일을 넣습니다.
3. `games.json`에 항목을 추가합니다.

```json
{
  "title": "My New Game",
  "description": "게임 설명",
  "thumbnail": "thumbs/my_new_game.png",
  "url": "games/my_new_game/index.html",
  "category": "ARCADE"
}
```

목록 순서대로 표시됩니다. 선택 항목인 `category`는 장르, `detail`은 상단 카드의 부가 정보입니다. 첫 게임에 `"featured": true`를 지정하면 큰 소개 카드로 표시됩니다. 소개 게임은 하나만 지정하세요.
