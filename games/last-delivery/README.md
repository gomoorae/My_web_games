# 마지막 표행 · 1.6

6×6에서 8×8까지 넓히는 보따리에 무기와 비급을 배치해 청하성까지 열 번의 고비를 넘는 무협 로그라이크.

## 바로 플레이

[웹에서 플레이](https://gomoorae.github.io/My_web_games/games/last-delivery/) · [게임 목록](https://gomoorae.github.io/My_web_games/)

배포 ZIP을 풀고 **Last-Delivery.html**을 브라우저에서 연다. 이 파일에 그림, 글꼴, 게임 코드가 모두 들어 있어 설치나 인터넷 연결이 필요 없다. 원본 작업 폴더에서는 `dist/index.html`도 직접 열 수 있다.

진행은 해당 브라우저에 자동 저장된다. 전투 중 다시 열면 일시정지 상태로 복원된다. 파일의 위치나 사용하는 브라우저를 바꾸면 다른 저장 공간으로 취급될 수 있다. 이전 3전 플레이판의 저장은 덮어쓰지 않는다.

## 1.6 변경 사항

- 휴대폰에서 하단 진행 / 내 보따리 / 상대 보따리 버튼으로 화면을 전환한다. 각 화면의 스크롤 위치를 기억하고 전투·보상·상점·휴식으로 바뀌면 진행 화면을 보여 준다.
- 보따리 바로 아래 선택한 물건의 회전·창고 이동·자동 배치·효과/연마·선택 해제를 제공한다. 창고 물건을 고르면 보따리로 이동해 빈칸을 눌러 배치할 수 있다.
- 320px 폭부터 작은 화면을 지원하고, 휴대폰 가로 화면·안전 영역·44px 주요 버튼·작은 화면 카드와 대화창을 조정했다. 8×8 보따리도 화면 폭 안에서 표시한다.
- 다른 보따리를 보는 중에도 전투의 일시정지·배속을 바꿀 수 있다. 전투 저장을 다시 열면 일시정지 상태로 복원한다.
- GitHub 게임 목록에 연결하고 웹판 그림을 WebP로 바꿨다. 이미지 파일 합계는 약 32.4MB에서 4.8MB로 줄었으며 원본 PNG는 로컬 작업 소스에 유지한다.

## 1.5 변경 사항

- 같은 종류의 보조품도 배치한 물건마다 효과를 합산한다. 독낭 2개를 한 무기에 붙이면 기본 공격 적중마다 중독 +2중첩, 3개면 +3중첩이다. 숫돌 2개는 해당 무기와 연결 무공의 피해 +50%, 3개는 +75%다.
- 이전 안내의 “한 번 적용”은 보조품 한 개의 여러 접촉면·연결 경로를 중복 계산하지 않는다는 뜻이었다. 서로 다른 독낭·숫돌을 같은 종류라는 이유로 제외하지 않는다는 점을 도감·도움말·연결 안내에 명시했다.
- 상점과 3전부터의 보상에서 보유한 보조품도 다시 나온다. 이전에는 무기·심법·무공만 중복 획득 후보에 포함되던 문제를 수정했다. 상점의 한 상품은 방문·새로고침마다 한 번 구매하며, 다른 상점·새로고침·보상에서 같은 보조품을 모을 수 있다.
- 무기·무공을 선택하면 실제 기여 중인 보조품의 종류별 개수와 보너스 합계를 표시한다. 창고·연결이 끊긴 보조품은 해당 장비의 합계에서 빠진다. 기본 공격 전용인 독낭 등의 중독·출혈·화상 보너스를 무공 효과로 표시하지 않는다.
- 기본 공격 속도 +80%, 재사용 시간 단축 50%, 치명타 확률 85%, 회피 50%, 대상의 중독·출혈·화상 각각 12중첩 등 기존 능력치 상한은 유지한다. 동일 보조품의 합산과 최종 능력치 상한은 별개의 규칙이다.

## 1.4 변경 사항

- 무기·심법·무공의 개수 제한을 없앴다. 보따리에 들어간 무기는 각각 자기 공격 주기로 공격하고, 심법은 모두 활성화되어 효과가 합산된다. 무공도 계열과 인접 조건만 맞으면 전부 활성화된다.
- 상점과 후반 보상에서 이미 보유한 무기·심법·무공을 다시 얻을 수 있어, 같은 종류를 여러 개 쓰는 배치도 가능하다. 상점의 아이템별 재고 제한은 그대로다.
- 모든 무공은 내공을 공유한다. 준비된 무공이 순환하며 발동 기회를 얻으므로, 여러 무공을 배치할 때 내공 회복·최대 내공·재사용 시간을 함께 고려한다.
- 비급 하나가 여러 무기에 닿아도 비급의 발동과 재사용 시간은 하나다. 보조품 한 개에서 여러 연결 경로로 한 무공에 도달한 효과는 한 번 계산한다. 같은 종류를 포함해 여러 보조품·심법은 각각 합산된다.
- 무기 보조품은 맞닿은 모든 무기와 해당 무기에 연결된 무공에 효과를 준다. 관계없는 다른 무기에는 전달하지 않는다. 중독·출혈·화상 추가는 기존 설명대로 기본 공격에 적용된다.
- 능력치에는 전체 무기의 합산 기본 DPS를 표시하고, 각 무기의 피해·공격 간격·DPS를 별도로 보여 준다. 무공별 연결 무기, 운용 중인 모든 심법도 확인할 수 있다. 공격·회피·재사용 등의 기존 수치 상한은 유지한다.
- 전투 중 모든 무기에 각각 재사용 표시와 발동 강조가 나온다. 적도 같은 다중 장비 규칙을 사용하고, 일부 후반 적은 무공·보조품을 줄이는 대신 추가 무기나 심법을 배치한다.
- 휴식 수련은 장착 무기 1개와 활성 무공 1개를 연마하며, 가능한 장비 중 연마 단계가 낮은 것을 고른다. 수련 버튼에 대상을 미리 표시한다.
- 기존 전투 저장의 기혈·시간·대기시간을 유지하며 새 장비 규칙으로 이어진다.

## 1.3 변경 사항

- 선택한 아이템의 현재 피해·공격 간격·무공 재사용 시간·방어막·회복량을 실제 전투 규칙으로 계산한다. 연마 누적 증가량과 다음 단계의 전후 수치를 함께 표시하며, 창고·비활성 물건은 조합 효과가 빠진 단독 성능으로 구분한다.
- 유료 연마와 휴식 수련 후 결과표에 연마 전 → 후, 증가량, 실제 기혈 회복량을 남긴다. 결과는 다시 열어도 유지되고 닫거나 다음 전투를 시작하면 정리된다.
- 보따리 능력치에 기본 공격 1타·초당 기본 피해·방어력·시작 방어막을 상시 표시한다. 상세창에서 내공·회복·치명타·관통과 각 활성 무공의 피해·재사용 시간을 확인한다. 기본 DPS는 무공·치명타·지속 피해와 상대 방어를 포함하지 않는다.
- 무공용 인접 보조품은 맞닿은 활성 무공 모두에 적용한다. 청동풍령의 재사용 15% 단축과 묵향염주의 무공 피해 +20%는 각 대상에 따로 계산하며, 떨어진 무공에는 적용하지 않는다. 현묵연은 인접 활성 무공 하나당 내공 회복 +0.4/초로 합산한다.
- 모든 유효 접촉면에 연결선을 표시하고, 보조품을 선택하면 적용 무공 수와 총 효과를 보여 준다. 같은 물건의 여러 면이 한 무공과 닿아도 한 번만 적용한다. 무기에 붙는 보조품의 설명된 무기·무공 효과와 전역 효과는 유지한다.
- 적의 검격·도격·찌르기·암기·장풍을 원본 그림의 방향에 맞춰 보정했다. 적에서 연우로 향하는 이동과 그림 방향을 따로 계산하고, 화면 비율이 달라도 투사체 꼬리가 이동 방향을 따른다.
- 기존 1.2 전투 저장은 기혈·시간·남은 재사용 시간을 유지하면서 무공별 인접 효과 계산을 보충한다.

## 1.2 변경 사항

- 60종 아이템에 24가지 형태를 적용했다. 29종은 ㄴ자·ㅜ자·엇갈림·ㄷ자·십자·고리 형태이며, 90°씩 네 방향으로 회전한다. 형태의 빈 홈은 실제 빈칸이고, 안쪽 접촉면도 인접 효과에 포함한다.
- 상점과 휴식에서 가로 또는 세로를 한 칸씩 확장한다. 기본 6×6, 최대 8×8, 장소마다 한 번이다. 상점 비용은 누적 확장에 따라 24·32·40·48 은전이며, 휴식 확장은 무료지만 치료·수련 기회를 대신 사용한다.
- 적에게도 실제 보따리가 있다. 표행의 시드와 전투 순서에 따라 구성이 정해지며, 후반에는 더 많은 비급·심법·보조품과 연마된 장비를 갖춘다. 미리 본 배치가 전투에서도 그대로 적용된다.
- 적과 플레이어가 같은 아이템·인접·내공·재사용·방어·소모품 규칙을 사용한다. 적에게 별도의 고정 공격 패턴이나 숨은 공격력·방어력을 더하지 않는다. 최종 보스의 절반 기혈 연출도 숨은 능력치 증가를 만들지 않는다.
- 새 전투의 누적 피해를 고려해 승리 후 기혈 회복을 최대 20으로 조정했다.
- 양쪽 보따리에서 사용한 아이템이 공격·방어·회복·소모에 맞춰 빛난다. 공격 무기와 비급은 재사용 시간·내공 대기를, 사용한 약품은 소모 상태를 표시한다. 효과에 기여한 보조품도 따로 강조한다.
- 이전 저장의 물건·은전·진행을 유지한다. 커진 형태가 겹치면 해당 물건만 창고로 옮긴다. 이전 규칙으로 진행 중이던 전투는 준비 화면부터 다시 시작하고, 새 규칙의 전투 저장은 그대로 이어진다.

## 1.1에서 유지한 개선

- 유효한 인접 연결을 맞닿은 면에 항상 표시한다. 금색 원은 무공, 청록색 마름모는 보조 효과다.
- 선택한 물건의 연결 상대와 실제 효과를 표시하고, 배치 예정 위치의 연결 생성·해제를 미리 보여 준다.
- 상시 효과와 자동 약품은 인접 연결과 구분한다.
- 컷씬은 한 인물의 정확한 그림 영역과 대사창을 별도 영역에 배치한다. 배경이 얼굴에 비치는 합성을 제거했다.
- 상점·휴식·보상·전투 모두 공통 상태창에 기혈, 은전, 무기, 심법, 방어막, 활성 무공을 표시한다. 스크롤할 때도 상태창을 유지한다.
- 창고에서 각 아이템의 ↻ 버튼으로 미리 회전한다. 크기와 회전 방향을 표시하며, 다시 선택하거나 저장을 불러와도 유지한다. 자동 배치도 현재 방향을 우선한다.
- 끌어 놓을 때 잡은 위치를 유지하고 가까운 빈칸으로 맞춘다. 보따리 가장자리와 칸 사이의 여백도 허용하며, 초록색 미리보기와 실제 배치가 일치한다.
- 적의 공격은 현재 연우의 몸통 위치에 타격 효과를 표시한다. 적에서 연우로 향하는 궤적, 피격 반응, 방어막 흡수와 기혈 피해 문구를 추가했다.
- 기존 1.0 저장 형식과 호환된다.

## 플레이 방법

- 검·도·창·암기·권법 중 시작 장비를 선택한다. 보따리는 6×6으로 시작하고 상점·휴식에서 최대 8×8까지 넓힐 수 있다.
- 물건을 끌어 놓거나, 선택하고 빈칸을 클릭한다. 초록색 미리보기가 실제 놓일 자리다. **R** 또는 창고의 **↻** 버튼으로 방향을 바꾼다.
- 무기·심법·무공은 개수 제한 없이 공간만큼 장착한다. 무기는 각각 공격하고 심법은 모두 효과를 낸다. 같은 계열의 비급을 무기의 옆면에 붙이면 초식이 활성화된다. 대각선은 연결되지 않는다.
- 연결 조건에 맞는 초식은 모두 활성화되며 내공을 공유한다. 하나의 비급이 여러 무기에 닿아도 중복 시전하지 않는다.
- 같은 종류의 보조품을 여러 개 배치해도 개별 효과를 합산한다. 보조품은 설명에 적힌 인접 조건을 따른다. 전역 보조품·심법·소모품은 보따리에 넣으면 사용할 수 있다. 창고의 물건은 발동하지 않는다.
- 전투는 자동 진행한다. 1배/2배속·일시정지를 지원하고, 다른 탭으로 이동하면 정지한다.
- 전리품은 창고에 들어간다. 새 장비는 다음 전투 전에 직접 배치한다.
- 무기·비급을 선택해 은전으로 최대 3단계 연마할 수 있다. 판매도 가능하지만 마지막 무기는 팔 수 없다.
- 2·5·8전 뒤 상점, 3·6·9전 뒤 휴식. 10전의 적운당주 곽진을 쓰러뜨리면 이야기의 결말에 도달한다.
- 무림 도감에서 모든 아이템의 크기·조건·효과를 살펴볼 수 있다.

## 구현된 내용

|---|---:|
| 무기 | 10 |
| 공격·방어·보조 무공 | 18 |
| 내공심법 | 6 |
| 보조품 | 16 |
| 소모품 | 10 |
| 전투 | 10 |
| 상점 / 휴식 | 각 3회 |
| 컷씬 | 6개, 대사 34줄 |

무공에는 연속 베기, 갑옷 관통, 출혈, 중독, 내공 봉쇄, 회복, 방어막, 기절, 처형, 화상 등의 서로 다른 효과가 있다. 전리품과 상점은 표행마다 달라진다. 마지막 보스는 연마된 장비와 비급 조합을 사용하며, 기혈 절반에서 결전 연출이 나온다.

전투용 전신 그림은 연우 6자세·적 8종이며, 전장 4곳·무공 효과 그림 12종·아이템 그림 60종을 새로 만들었다. 18개 무공마다 효과의 순서·궤적·타격 위치를 구분했다. 효과음과 배경음은 브라우저에서 합성한다.

## 소스 수정

ZIP에는 그림을 중복 저장하지 않기 위해 HTML 안에 넣었다. 소스를 수정하려면 먼저 `node restore-assets.mjs`를 실행하면 원본 그림·글꼴이 `dist/assets`에 복원된다. 별도 패키지 설치는 필요 없다.

- `dist/data.mjs`: 아이템·적·시작 계열·대사.
- `dist/engine.mjs`: 양측 공통 전투·능력치·보상·상점·저장 검증과 이전 저장 전환.
- `dist/performance.mjs`, `dist/performance-ui.mjs`, `dist/performance.css`: 실제 능력치·무공별 성능·연마 비교와 결과 표시.
- `dist/grid.mjs`: 형태·회전·충돌·접촉면 계산.
- `dist/expansion.mjs`: 확장 선택·비용·크기 제한.
- `dist/enemy-loadouts.mjs`: 시드에 따른 적의 실제 보따리 구성.
- `dist/inventory-board.mjs`, `dist/inventory-board.css`: 형태 표시와 상대 보따리 열람.
- `dist/app.mjs`: 화면·입력·저장·합성 오디오.
- `dist/placement.mjs`: 가까운 유효 위치 검색과 배치 보정.
- `dist/vfx.mjs`, `dist/vfx.css`: 무기·초식·적 공격별 전투 연출.
- `dist/style.css`: 반응형 화면과 그림 아틀라스 표시.
- `dist/adjacency.mjs`, `dist/inventory-ui.mjs`, `dist/inventory.css`: 실제 인접 관계·접촉면·배치 미리보기·상태창.
- `dist/cutscene.mjs`, `dist/cutscene.css`: 인물과 대사창을 분리한 컷씬.
- `node build.mjs`: 모듈을 직접 실행 가능한 `dist/game.js`로 묶는다.
- `npm test`: 규칙과 화면 컨트롤러 검사.
- `node export.mjs`: 완전한 단일 실행 파일 `release/Last-Delivery.html`을 만든다.
- `npm start`: 개발용 정적 HTTP 서버.
- `npm install` 후 `npm run publish:web`: 이미지 압축과 소스·검사를 포함한 웹판을 `release/web`에 만든다. 첫 화면은 루트 `index.html`이며 소스는 `dist/`에 있다. 원본 작업 폴더의 PNG를 웹판에서 WebP로 변환한다.
- `node tests/balance.mjs`: 정상 자원으로 여러 시작 계열과 시드를 자동 진행한다.
- `node tests/balance.mjs 5 --multiple`: 복수 무기·심법을 쓰는 전략으로 계열당 5개 시드를 자동 진행한다.

## 검증 범위

다중 무기·심법·무공과 인접 효과, 개별 공격 주기, 연마 전후, 배낭 능력치, 적 이펙트 방향, 저장 복원을 포함한 자동 검사 149개를 통과했다. 같은 종류 보조품의 개별 합산·사용 이펙트 출처·장비별 표시와 중복 구매·보상 획득도 포함한다. 다섯 시작 계열 모두 정상적인 전리품·상점·획득 은전으로 무기 2개와 심법 2~3개를 운용하며, UI 버튼을 조작해 10전·모든 컷씬·엔딩·저장 복원까지 이어지는 경로를 확인했다. 이전 1.2판의 별도 25회 자동 전략 실험에서는 8회 완주했고, 나머지는 8~10전에서 종료됐다. 이전 판의 간단한 자동 전략 결과이며 이번 인접 규칙의 승률이나 사람의 체감 재미를 뜻하지 않는다. 이전 판의 100회 완주율은 변경된 전투 규칙에 적용하지 않는다.

Chromium 실제 렌더링과 터치 에뮬레이션에서 선택·창고 이동·회전·빈칸 배치·상대 보따리 확인·일시정지·배속·전투 저장 복원을 확인했다. 320·360·390·768·844·1440px 폭에서 준비·보상·상점·휴식과 8×8 보따리의 가로 넘침이 없음을 확인했다. 자동 검사와 브라우저 검사에서 사용한 진행용 데이터는 검사용이며 실제 휴대폰 기기의 터치감·Safari·스피커 출력 검사는 별도다.

## 아트와 글꼴

모든 원화는 이 게임을 위해 생성했다. 인물·초식 효과의 실제 PNG 알파 채널을 확인했다. CSS 아틀라스로 표시하며, 일부 길게 뻗은 무기의 끝이 타일 경계에서 조금 잘릴 수 있다.

Noto Serif KR을 바탕으로 필요한 글자를 묶고 이름을 Last Delivery Serif로 변경했다. SIL OFL 1.1은 `dist/assets/NotoSerif-LICENSE.txt`와 실행 HTML 안에 포함한다.
