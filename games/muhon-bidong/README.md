# 무혼 비동

1.31.0 · 경공과 반격으로 네 비동을 돌파하는 픽셀 무협 액션.

[바로 플레이](https://gomoorae.github.io/My_web_games/games/muhon-bidong/?v=1.31.0) · [게임 목록](../../index.html)

낙검회랑, 청뢰잔도, 적염심연, 무혼심처를 지나 네 무혼을 상대합니다. 장애물과 특수기는 피하고, 날아오는 무기를 반격해 길을 여세요. 무혼을 꺾으면 능력을 이어받고 다음 지역으로 진행합니다.

진기는 기본 15초마다 한 칸 자동 회복됩니다. 청명심법을 고르면 12초, 두 번 고르면 9초로 줄어듭니다. 파쇄강기는 반격으로 되돌린 무기의 피해를 +15%, 두 번 고르면 총 +30% 높입니다. 금강호흡은 최대 진기를 한 칸씩 늘립니다. 각 보상은 최대 두 번 선택합니다. 이동 구간의 회복 아이템과 구간 통과 회복은 없으며, 보스 진입 전과 처치 후 다음 지역으로 떠날 때는 완전히 회복합니다.

맞으면 호신강기가 진기 한 칸으로 방어하며 짧은 피격 자세와 충돌음이 나옵니다. 경공과 반격은 계속 조작할 수 있습니다. 진기가 없는 상태에서 다시 맞으면 추락하고 쓰러집니다. 설정에서 화면 흔들림과 입자를 줄일 수 있습니다.

마지막 비동의 발사원은 조준 표창 두 발을 먼저 던지고, 간격을 둔 뒤 반격 가능한 무기를 상·중·하로 연사합니다. 표창은 쳐내도 화면 밖으로 빠지고, 후속 무기를 되돌리면 발사원을 파괴합니다. 전반부에도 검객 네 명이 더 등장해 총 열 명을 상대합니다.

## 조작

| 행동 | PC | 모바일 |
| --- | --- | --- |
| 경공 상승 | Space / W / ↑ 누르고 있기 | 화면 왼쪽 어디든 누르고 있기 |
| 하강 | 상승 키 떼기 | 왼쪽 손가락 떼기 |
| 반격 | J / X | 화면 오른쪽 어디든 터치 |
| 일시정지 | Esc | 화면의 Ⅱ 버튼 |
| 계속·재도전·메뉴 선택 | Space / Enter | 해당 버튼 터치 |
| 메뉴 항목 이동 | 방향키 / Tab | 해당 항목 터치 |

휴대폰은 가로 화면을 권장합니다. 진행 위치, 열린 비동과 기록은 현재 브라우저에 자동 저장됩니다. 수련은 여정 저장을 바꾸지 않습니다. 공개 사이트를 정식 플레이 주소로 사용합니다.
