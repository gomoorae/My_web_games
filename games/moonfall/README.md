# 월하무쌍 · Web

[웹에서 플레이](https://gomoorae.github.io/My_web_games/games/moonfall/) · [게임 목록](../../index.html)

월하무쌍 1.5.1의 PC 브라우저판입니다. Godot 4.7.1의 WebGL 2·WebAssembly 내보내기를 사용하며 별도 설치나 계정은 필요 없습니다. PC 화면 안내는 키보드 중심이며, 휴대폰에는 [모바일 시험판](../moonfall-mobile/)을 제공합니다.

세 전장에서 한 명의 무인으로 6분을 생존한 뒤 마지막 고수를 쓰러뜨립니다. 여덟 시작 무공을 고를 수 있고, 재료 두 무공을 각각 5단계까지 올리면 합성이 열립니다. 한 판에는 무공 네 종류와 합성 비기 두 개를 익힐 수 있습니다.

1.3.1에서는 출전 전에 Wuxia 01, 전투에서는 무작위로 선택한 Wuxia 02·03을 재생합니다. 곡이 끝나면 다른 전투곡으로 이어집니다. 영약 생성 확률은 일반 적 2.8%→1.4%, 고수 100%→50%로 줄였으며 영약 하나의 회복량 28과 상자·흡성 아이템은 유지합니다.

1.3.2는 웹 전용 성능 개선판입니다. 음악을 브라우저가 직접 재생하도록 바꿔 전투 화면 처리 지연의 영향을 줄였습니다. 고해상도 화면에서도 게임 내부 렌더링을 1440×900으로 제한하고 반복되는 UI와 지형 계산을 재사용합니다. 적 수·공격·성장·영약 확률은 그대로입니다.

1.3.3에서는 영약 확률을 전투 시간에 따라 조절합니다. 첫 3분은 일반 적 1.4%·고수 50%를 유지하고, 3~6분 사이에 서서히 줄어 6분 이후에는 일반 적 0.7%·고수 25%가 됩니다. 일시정지·수련 선택 중에는 감소하지 않으며 회복량 28과 다른 보상은 그대로입니다.

1.4.0에서는 근접 연타 **파쇄권**과 중거리 회전 발차기 **유운각**을 추가했습니다. 시작 무공은 1–8이나 방향키로 고릅니다. 파쇄권+호신강기의 **금강연환권**, 파쇄권+유운각의 **용호난무**, 유운각+홍련진의 **홍련선풍각**으로 합성은 총 아홉 가지입니다. Tab으로 연 비급은 좌우 방향키나 아래 버튼으로 넘깁니다. 무공 네 종류·합성 두 개·5+5 조건과 후반 영약 감소는 유지됩니다.

1.4.1에서는 파쇄권이 매 타격마다 근거리 표적을 다시 고릅니다. 이번 연타에서 덜 맞은 적을 우선해 여러 방향으로 나누어 때리고, 적이 하나면 집중 공격합니다. 기존 피해량·사거리·연타 수와 끝타의 강한 밀치기는 유지됩니다.

1.5.0에서는 청죽림·적염관의 주기적인 장판과 일반 적·고수의 장판을 제거했습니다. 청죽림은 자객의 포위, 적염관은 중장갑 적과 빠른 적의 대열이 주된 위협입니다. 보스의 독진과 불길은 유지합니다.

1.5.1에서는 일반 적 영약 확률이 0.7%→0.35%, 흡성 확률이 0.35%→0.175%로 전투 3~6분 사이에 감소합니다. 고수는 영약과 흡성을 모두 확정 생성합니다.

## 실행 파일

- `index.html`은 시작 화면·전체 화면·조작 안내입니다.
- `game/index.html`과 같은 폴더의 `.js`, `.wasm`, `.pck`, 아이콘은 함께 배포하는 Godot 웹 빌드입니다. 파일명과 상대 경로를 유지하세요.
- 빌드는 단일 스레드이며 서비스 워커를 사용하지 않아 일반 GitHub Pages에서 실행할 수 있습니다.
- 최초 게임 파일은 약 73MiB입니다. 실제 전송량과 대기 시간은 서버 압축·브라우저 캐시·연결 속도에 따라 달라집니다.

기록과 최근 선택·소리 설정은 같은 브라우저의 사이트 저장소에 남습니다. 사이트 데이터를 지우거나 다른 브라우저로 바꾸면 공유되지 않습니다. 진행 중인 전투의 이어 하기는 제공하지 않습니다.
