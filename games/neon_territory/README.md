# NEON TERRITORY · v0.5.0

선을 이어 적이 없는 땅을 확보하는 PC·모바일 땅따먹기입니다. 서로 다른 지형과 네 가지 적 유형이 등장하는 10스테이지, 영역 확보 연출·효과음, 점수와 메달, 자동 저장을 제공합니다.

[웹에서 플레이](https://gomoorae.github.io/My_web_games/games/neon_territory/?v=0.5.0)

## 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | 방향키 / WASD | 방향패드를 누르고 유지. 손가락을 누른 채 밀면 방향 전환 |
| 선 긋기 준비 / 해제 | Space | 선 긋기 버튼 |
| 긴급 귀환 | X | 긴급 귀환 · ♥1 버튼 |
| 일시정지 / 계속 | P / Esc | 일시정지 / 계속하기 버튼 |
| 스테이지 선택 | M 또는 메뉴 | 메뉴 |
| 화면 확대 / 복원 | F 또는 화면 확대 | 화면 확대 |
| 효과음 | 상단 소리 버튼 | 상단 소리 버튼 |

패드 중앙으로 손가락을 옮기거나 떼면 이동을 멈춥니다. 방향패드를 누른 상태에서 다른 손가락으로 선 긋기 버튼을 사용할 수 있습니다. 모바일 세로·가로 화면을 지원하며 화면 크기에 맞춰 조작부와 게임판을 배치합니다. 전체화면 API가 없는 브라우저에서는 화면 확대 모드를 사용합니다.

## 플레이 규칙

1. 민트색 안전 영역에서 출발합니다. 안전 영역 안에서는 선을 그릴 때보다 **1.6배 빠르게** 이동합니다.
2. 선 긋기를 켜고 어두운 땅으로 나갑니다. 노란 선을 안전 영역에 연결하면 선과 **적이 없는 구역**을 확보합니다. 처음부터 놓인 안전 섬도 귀환 지점으로 사용할 수 있습니다.
3. 나뉜 양쪽 구역에 적이 남아 있으면 선만 확보합니다. 이 경우 안내가 이유를 알려줍니다. 초기 안전 지형은 확보율의 분모에서 제외하며, 매 스테이지는 0%부터 시작합니다.
4. 적이 미완성 선에 닿으면 기회 하나를 잃고 출발점으로 돌아옵니다. 그리던 선만 지워지며 이미 확보한 땅은 유지됩니다.
5. 자신의 선은 통과할 수 없습니다. 선에 갇히면 경고가 나오며 **긴급 귀환**으로 기회 하나를 소비하고 출발점으로 돌아갈 수 있습니다. 마지막 기회를 쓰는 귀환은 확인 후 실행합니다.
6. 목표 점유율에 도달하면 다음 스테이지가 열립니다. 각 판은 기회 3회로 시작하고, 실패 시 현재 스테이지에서 재도전할 수 있습니다.

창·탭 전환과 화면 회전 시 자동으로 일시정지합니다. 다시 시작할 때는 **계속하기**를 누릅니다. 제한 시간은 없습니다.

## 적과 스테이지

| 적 | 표시 | 움직임 |
|---|---|---|
| 유영형 | 분홍 원 | 벽에서 반사하고 짧은 예고 후 방향 전환 |
| 반사형 | 보라 사각형 | 직선을 유지하며 벽에서 반사 |
| 추적형 | 주황 마름모 | 선을 그릴 때 현재 위치를 겨냥한 방향을 예고한 뒤 전환 |
| 돌진형 | 파랑 화살표 | 방향을 예고한 뒤 짧게 돌진. 돌진 중에는 방향 추적 없음 |

예고선은 다음 진행 방향을 보여줍니다. 추적형은 0.5초, 돌진형은 0.65초 동안 예고하며 돌진은 0.55초간 이어집니다. 모든 적은 안전 영역을 통과할 수 없습니다.

| 스테이지 | 이름 | 적 | 목표 | 지형과 주요 변화 |
|---|---|---:|---:|---|
| 1 | 첫 번째 경계 | 3 | 75% | 열린 보드, 유영형으로 기본 규칙 익히기 |
| 2 | 반사의 법칙 | 3 | 75% | 직선 반사형 등장 |
| 3 | 안전한 섬 | 4 | 78% | 중앙 안전 섬 |
| 4 | 선을 읽는 자 | 4 | 80% | 왼쪽 안전 반도, 추적형 등장 |
| 5 | 두 개의 등대 | 5 | 82% | 서로 다른 위치의 두 안전 섬 |
| 6 | 돌진 경보 | 5 | 83% | 양쪽 안전 반도, 돌진형 등장 |
| 7 | 세 개의 징검다리 | 6 | 83% | 세 안전 섬과 네 유형의 적 |
| 8 | 엇갈린 해안 | 6 | 84% | 엇갈린 반도, 추적·돌진 조합 |
| 9 | 중앙 거점 | 7 | 85% | 큰 중앙 안전 거점 |
| 10 | 마지막 경계 | 7 | 86% | 양쪽 반도와 중앙 섬, 네 유형의 적 |

## 점수와 기록

한 번에 확보한 점유율 증가량을 `g`라고 할 때 기본 점수는 `round(g × 100)`입니다. 선 이외의 빈 땅도 확보하면 `round(g × 100 + g² × 8)`을 받으므로 큰 영역을 한 번에 차지할수록 유리합니다.

- 클리어 보너스: 남은 기회당 **1,000점** + `max(0, round(180 − 플레이 시간[초])) × 10점`.
- 메달: 남은 기회 **3회는 금**, **2회는 은**, **1회는 동**.
- 스테이지별 최고 점수·최단 시간·최대 단일 확보율·최고 메달을 각각 저장합니다. 서로 다른 도전에서 세운 기록일 수 있습니다.
- 내 기록 화면의 합계는 **스테이지별 최고 점수의 합**입니다.

## 자동 저장과 이어하기

진행 중인 위치·적·미완성 선·시간·점수, 해금한 스테이지, 최고 기록과 소리 설정을 **현재 브라우저의 로컬 저장소**에 저장합니다. 플레이 중 주기적으로 저장하고, 영역 확보·기회 소모·클리어·일시정지·페이지 이탈 때도 저장합니다.

다시 열면 진행 중인 판은 일시정지 상태로 복원됩니다. 성공·실패·최종 완주 화면도 유지합니다. 메뉴에서 해금한 스테이지를 새로 시작해도 최고 기록과 해금은 남습니다. 브라우저 저장소를 지우거나 다른 브라우저·기기로 접속하면 기록이 공유되지 않습니다. 저장이 불가능한 환경에서도 게임은 실행되며 화면에 저장 불가 상태를 표시합니다.

## 로컬 실행과 파일 구성

이제 HTML 한 파일이 아니라 아래 파일들을 **같은 폴더에 함께 유지**해야 합니다. 별도 설치나 외부 리소스 다운로드는 필요하지 않습니다.

- `index.html`: 화면 구조와 게임 진입점
- `styles.css`: PC·모바일 세로·가로·화면 확대 레이아웃
- `engine.js`: 영역 판정, 적 행동, 점수, 진행 복원 검증
- `controls.js`: 키보드·터치 패드 입력
- `progress.js`: 자동 저장, 스테이지 해금, 최고 기록
- `game.js`: 화면 연결, 캔버스 연출, 효과음, 메뉴
- `tests/`: 엔진·입력·기록 검증

폴더를 유지한 채 `index.html`을 열어 실행할 수 있습니다. 웹 배포와 같은 주소 방식으로 확인하려면 저장소 루트에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 5500
```

브라우저에서 `http://localhost:5500/games/neon_territory/`를 엽니다.

## 검증

저장소 루트에서 Node.js 기본 테스트 러너를 사용합니다. 외부 테스트 패키지는 필요하지 않습니다.

```sh
node --test games/neon_territory/tests/*.test.cjs
```

포획과 선만 확보한 경우, 귀환 직전 충돌, 갇힘·긴급 귀환, 안전 영역 가속, 10스테이지 이동 안정성, 진행·완주 복원과 손상 데이터, 키보드·터치 입력, 최고 기록 저장을 검증합니다.
