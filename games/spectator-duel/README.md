# 일기토 - 무장결투

조운과 여포를 비롯한 장수 40명 가운데 두 사람을 고르고 기마 일기토를 관전하는 픽셀 게임입니다. 매 대결마다 새로운 승부가 펼쳐집니다.

[게임 시작](https://gomoorae.github.io/My_web_games/games/spectator-duel/) · [게임 목록](https://gomoorae.github.io/My_web_games/)

타이틀에서 **게임 시작**을 누른 뒤 장수와 전투 방식을 고르세요. PC에서는 Enter 또는 Space로 시작할 수도 있습니다. 관전 중에는 화면 버튼으로 일시정지와 2배속을 조절하고, 키보드에서는 Space로 멈추거나 Enter로 소개와 필살 컷인을 넘깁니다. 휴대폰은 가로로 돌리면 두 기수가 더 크게 보입니다.

장수 선택 위의 **토너먼트**에서 8강·16강·32강을 편성합니다. 원하는 자리에 장수를 지정하고 **빈자리 추첨**으로 나머지를 채우세요. 연전은 승자의 남은 체력에 40을 더해 최대 100으로 다음 경기를 시작합니다. 완전 회복도 고를 수 있습니다. 원하는 경기만 관전하거나 관심 장수·결승 직전까지 진행할 수 있고, 진행 중 대회는 같은 브라우저에서 이어집니다.

화면 위쪽의 **← 게임 목록**을 누르면 같은 탭에서 다른 게임을 고를 수 있습니다. 키보드로는 Alt+G를 누르세요.

PC에서는 게임 화면을 최대 1280×720으로 가운데에 표시합니다. 더 작은 창에서는 가로와 세로에 맞게 줄어듭니다.

제작은 gomoorae, 게임 버전은 1.1.0입니다. 장수 원화와 기마 그래픽은 이 게임을 위해 제작했으며, 배경 연주곡 ‘풍운의 깃발’과 ‘철마의 질주’는 Google Flow Music으로 만들었습니다.
