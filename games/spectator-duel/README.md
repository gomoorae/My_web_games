# 일기토 - 무장결투

조운과 여포를 비롯한 장수 40명 가운데 두 사람을 고르고 기마 일기토를 관전하는 픽셀 게임입니다. 매 대결마다 새로운 승부가 펼쳐집니다.

[게임 시작](https://gomoorae.github.io/My_web_games/games/spectator-duel/) · [게임 목록](https://gomoorae.github.io/My_web_games/)

타이틀에서 **게임 시작**을 누른 뒤 장수와 전투 방식을 고르세요. PC에서는 Enter 또는 Space로 시작할 수도 있습니다. 관전 중에는 화면 버튼으로 일시정지와 2배속을 조절하고, 키보드에서는 Space로 멈추거나 Enter로 소개와 필살 컷인을 넘깁니다. 휴대폰은 가로로 돌리면 두 기수가 더 크게 보입니다.

화면 위쪽의 **← 게임 목록**을 누르면 같은 탭에서 다른 게임을 고를 수 있습니다.

제작은 gomoorae, 게임 버전은 1.0.0입니다. 장수 원화와 기마 그래픽은 이 게임을 위해 제작했으며, 배경 연주곡 ‘풍운의 깃발’과 ‘철마의 질주’는 Google Flow Music으로 만들었습니다.
