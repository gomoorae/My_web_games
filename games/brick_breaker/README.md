# 벽돌 깨기 · Brick Breaker 2.0.0

설치나 외부 라이브러리 없이 실행하는 Canvas 게임입니다. 경기장, 상태 표시와 조작 버튼은 화면 높이에 맞춰 배치합니다. PC를 기본으로 마우스·키보드를 지원하고, 휴대폰에서는 화면 드래그로 패들을 움직입니다.

## 조작

- 이동: 방향키, A/D, 마우스 이동 또는 화면 드래그.
- 발사: Space, 화면의 발사 버튼, PC 게임 화면 클릭. 공을 잃거나 다음 단계로 넘어가도 직접 발사할 때까지 기다립니다.
- 일시정지/계속: Esc 또는 버튼. 창이나 탭을 벗어나면 자동으로 정지합니다.
- 처음부터: R 또는 다시 시작. 진행 중에는 확인 화면이 먼저 나옵니다.
- 소리 버튼과 최고 점수는 브라우저에 저장합니다. 저장을 사용할 수 없어도 플레이할 수 있습니다.

## 게임 규칙

10개의 서로 다른 배치, 최대 3회 내구도의 벽돌, 주변 두 줄과 양옆을 연쇄 파괴하는 폭발 벽돌이 있습니다. 첫 스테이지는 40개 벽돌이며, 후반에도 벽돌을 과도하게 늘리지 않습니다.

- 멀티볼: 각 공을 3갈래로 분열, 최대 9개. 최대치에서 획득하면 150점.
- 와이드 패들: 14초 동안 폭 1.5배. 재획득하면 14초로 갱신.
- 관통 공: 9초 동안 벽돌을 즉시 파괴하며 통과. 재획득하면 9초로 갱신.
- 5개 연속 파괴마다 배율 +1, 최대 5배. 패들에 닿거나 기회를 잃으면 콤보 초기화.
- 모든 공을 놓쳤을 때만 기회 -1. 3·6·9단계 완료 시 기회 +1, 최대 5회.
- 마지막 3개 이하에서는 패들 중앙 28% 안으로 받으면 가까운 벽돌을 향해 반사하는 보조 조준이 켜집니다.

## 구현과 검사

- `engine.js`: DOM과 독립적인 게임 상태·연속 충돌 판정·초당 120회 고정 간격 계산. 벽돌의 면과 둥근 모서리를 구분하고, 관통/분열의 중복 접촉을 방지합니다.
- `app.js`: 입력, 화면, 효과음, 시각 효과, 최고 기록. 숨김/포커스 해제 시 입력을 비우고 정지합니다.
- `style.css`, `index.html`: 화면 크기 대응, 조작과 안내. 그림과 효과음은 자체 생성하며 외부 다운로드가 없습니다.

저장소 루트에서 정적 서버를 실행하고 `/games/brick_breaker/`를 엽니다. 검사에는 Node.js만 필요합니다.

```sh
node --test games/brick_breaker/tests/engine.test.cjs games/brick_breaker/tests/input.test.cjs
node games/brick_breaker/tests/playthrough.cjs
```

29개 회귀 검사: 30/60/120/144 Hz 결과 일치, 옆면/모서리/고속 충돌, 패들 끝, 아이템, 승패, 재시작, 포인터 취소, 다중 터치, 저장 실패, 화면 회전을 포함합니다. 자동 진행은 3개 경기장 높이와 3개 난수 시드 조합으로 9회 진행하며 90개 스테이지 완료를 확인합니다. 자동 플레이 결과는 사람의 체감 난도를 뜻하지 않습니다.

브라우저 화면 검사는 320×568, 390×844, 844×390, 1280×720, 1440×900 기준입니다. 실제 휴대폰의 터치감·소리·장시간 성능은 별도 실기 확인 대상입니다.
