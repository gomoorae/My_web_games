# 세로형 주행 화면 · 사고 연출 검증

버전: `3.1.0`. 검증일: 2026-10-14.

## 변경

- 주행 화면은 가로·세로 비율 최대 5:8로 중앙에 배치됩니다. 긴 휴대폰 화면은 가로 폭을 모두 사용합니다. 작은 창에서는 세로형 UI 전체를 축소하며 도로 이미지를 비율과 다르게 늘이지 않습니다.
- 전체 화면도 바깥 프레임을 확대해 같은 세로형 주행 구도를 유지합니다. 화면 크기와 컨테이너 크기 변경을 관찰해 캔버스를 다시 맞춥니다.
- 사고 시 주행과 점수를 즉시 확정하고, 약 2.65초 동안 불꽃·파편, 차체 파손, 떨어진 앞바퀴, 운전자의 공중 회전과 두 번의 튕김을 보여준 뒤 결과를 표시합니다.
- 결과 보기 버튼으로 연출을 건너뛸 수 있습니다. R / Space로 즉시 재도전하면 이전 연출을 완전히 초기화합니다. 지연된 결과 화면이 다음 주행에 끼어들지 않도록 별도 타이머를 사용하지 않습니다.
- 동작 줄이기 설정에서는 비행·흔들림 없이 정지된 파손 장면을 0.6초 표시합니다.
- 주행 물리·교통 규칙·점수·저장 키·기존 효과음은 유지합니다. `core.mjs`는 버전 줄 이외에 3.0.0과 동일합니다.

## 자동 검사

`node --test games/bike_game/tests/*.test.mjs`: 49개 통과.

- 기존 40개 교통·충돌·조향·오디오 검사.
- 넓은 모니터의 세로 비율, 휴대폰 폭 사용, 작은 가로 창에서 축소된 버튼 배치.
- 사고 연출의 시작·지연·단일 완료, 비행과 튕김 이후 정지, 좌우 충돌의 반대 방향 이동.
- 건너뛰기·초기화 시 실제 주행 상태 불변, 긴 프레임 간격에서 연출 전체가 사라지지 않음, 동작 줄이기 시 정지된 장면.

`node games/bike_game/tests/drive-check.mjs`: 32개 배치 × 90초 통과.

- 차선 변경 1,109회 시작, 1,093회 완료, 종료 시 진행 중 16회. 차체 겹침이나 미완료 차량 삭제 없음.
- 차량 최대 23대. 28,800개 횡단면 검사에서 도로 전체가 막힌 순간 없음.
- 무입력 72회와 커브만 보정하는 48회 결과는 3.0.0과 동일합니다.

## 실제 브라우저 확인

| 브라우저 크기 | 주행 프레임 크기 |
|---|---|
| 1920 × 1080 | 675 × 1080 |
| 1280 × 720 | 450 × 720 |
| 390 × 844 | 390 × 844 |
| 320 × 568 | 320 × 568 |
| 844 × 390 | 243.75 × 390 |
| 568 × 320 | 200 × 320 |

- 모든 크기에서 제목·시작·효과음 버튼이 프레임 안에 표시됐습니다. 568 × 320에서도 결과·재도전 버튼이 프레임 안에 있었습니다.
- 전체 화면 진입에서 677.5 × 1084 프레임을 확인했고, 종료 후 450 × 720으로 복귀했습니다.
- 키보드와 390 × 844 화면의 조향 버튼으로 충돌을 발생시켰습니다. 사고 연출 중 결과 화면은 숨겨지고 입력 눌림은 해제됐습니다. 운전자 비행·분리된 바퀴·파손 차체를 화면에서 확인했습니다.
- 연출 종료 후 결과 표시, 결과 보기로 즉시 건너뛰기, 연출 중 R 재도전 후 일시정지 상태 유지, 새로고침 후 기존 기록 유지, 브라우저 오류 없음 확인.

## 범위

화면 크기와 버튼 검사는 데스크톱 브라우저에서 수행했습니다. 실제 휴대폰의 터치감·발열·장시간 성능은 확인하지 않았습니다. 공개 파일 일치 여부와 공개 주소 실행은 배포 후 별도 검증 기록에 남깁니다.
