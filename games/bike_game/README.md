# 바이크 칼치기 · 생존 시험판 01

버전 `3.0.0-alpha.1`. 좌우 조향만으로 계속 바뀌는 차량 사이의 틈을 통과하는 생존 아케이드입니다. 한 번 충돌하면 종료되며, 같은 차량 배치로 바로 재도전할 수 있습니다.

## 조작

- 좌우 방향키 / A, D: 조향. 손을 떼면 즉시 횡이동이 멈춥니다.
- 휴대폰: 화면 아래 왼쪽·오른쪽 버튼. 동시에 누르면 중립이며 손가락을 떼거나 입력이 취소되면 해제됩니다.
- Esc / P 또는 상단 Ⅱ: 일시정지 / 계속.
- R 또는 결과 화면의 재도전: 같은 배치를 처음부터 다시 시작.
- 결과 화면의 Space도 재도전합니다. 처음 화면에서 새로 시작하면 다른 배치가 선택됩니다.

가속·제동·부스트 조작은 없습니다. 주행 속도는 자동이며, 커브가 플레이어를 옆으로 밀지 않습니다. 차나 가드레일에 한 번 부딪히면 해당 시도가 끝납니다. 6km 제한, 내구도 회복, 완주 보너스도 없습니다.

## 첫 시험판의 범위

야간 도로 한 곳과 세 가지 차량 무리에 집중합니다.

1. 엇갈린 무리: 이어지는 통과 위치가 서로 바뀝니다.
2. 끼어들기: 방향지시등을 켠 차량이 넓은 틈으로 들어와 통과 공간을 좁힙니다. 신호는 이동보다 1.2초 먼저 시작합니다.
3. 트럭: 더 넓고 긴 차체 사이로 다음 탈출 위치를 읽으며 통과합니다.

차량 무리 전체의 안전한 틈이 정해진 차선 경계에 고정되지 않습니다. 앞 무리를 빠져나온 후 다음 틈에 도달할 수 있도록 차량 길이와 조향 속도를 고려한 간격을 둡니다. 초반의 넓은 틈은 서서히 좁아지며, 세 무리 묶음마다 잠깐 여유가 있습니다. 배치는 플레이어의 위치를 보고 바뀌지 않고 시드에 따라 미리 결정됩니다.

## 점수

- 생존: 초당 5점. 차량 추월: 대당 20점. 차량 무리 통과: 80점.
- 근접 추월: 100 × 콤보. 더 가까운 PERFECT SPLIT: 180 × 콤보.
- 양옆을 좁게 통과하는 DOUBLE SPLIT: 180 × 콤보. 무리당 한 번만 지급합니다.
- 콤보는 정밀 통과 후 4.5초 동안 이어지며 최대 10배입니다.
- 최고 점수와 최장 생존 시간은 현재 브라우저에 저장됩니다. 이전 2.0 기록은 기존 키에 남고, 생존 시험판 기록과 섞이지 않습니다.

## 구조 / 실행

`index.html`·`styles.css`는 화면, `app.mjs`는 입력·저장·상태 연결, `core.mjs`는 120Hz 규칙, `renderer.mjs`는 원근 도로와 차량, `audio.mjs`는 엔진·바람·추월·충돌 소리입니다. 게임 규칙은 화면 픽셀과 분리되어 있습니다. `racing-game.html`은 현재 게임으로 이동하는 이전 주소입니다.

설치나 빌드 없이 저장소 루트에서 정적 서버를 실행하고 `/games/bike_game/`를 엽니다.

```sh
python3 -m http.server 8877
node --test games/bike_game/tests/core.test.mjs
node games/bike_game/tests/drive-check.mjs
```

자동 검사는 고정 안전 통로, 단순 반복 조작의 허점, 물리적으로 도달할 수 없는 배치를 찾기 위한 것입니다. 화면을 읽는 난이도와 회피의 손맛은 사용자 플레이로 확인하고 조정합니다. 현재 검증 범위는 `VERIFICATION_3.0.0-alpha.1.md`를 참고하세요.
