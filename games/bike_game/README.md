# 바이크 칼치기 · MIDNIGHT SPLIT 2.0.0

바이크 뒤에서 밤의 고속도로를 바라보는 아케이드 주행 게임입니다. 강변 진입로, 빛의 터널, 도심 순환선을 거쳐 6km를 달립니다. 가까이 추월할수록 콤보와 부스트가 쌓입니다.

## 조작

| 동작 | 키보드 | 터치 |
|---|---|---|
| 조향 | 방향키 좌우 / A, D | 왼쪽·오른쪽 버튼 |
| 가속 | ↑ / W | GAS |
| 브레이크 | ↓ / S / Space | BRAKE |
| 부스트 | Shift | NITRO |
| 일시정지 / 계속 | Esc / P | 상단 Ⅱ / 계속 달리기 |
| 다시 시작 | R | 결과 또는 일시정지 화면 버튼 |

전진은 자동입니다. 커브에서는 안쪽으로 부드럽게 조향하세요. 차선을 바꾸는 차량은 방향지시등으로 미리 알립니다. 부스트 중에도 브레이크가 우선합니다. 화면을 벗어나면 자동으로 멈춥니다. 세로·가로 화면 모두 조작 버튼을 지원합니다.

## 규칙

- 기본 순항 164km/h, 가속 206km/h, 부스트 252km/h, 브레이크 78km/h. 실제 속도는 부드럽게 변하며 갓길과 충돌에서는 감속합니다.
- 일반 추월 30점. 115km/h 이상으로 차량 가까이 추월하면 150점 × 콤보, 더 가까운 PERFECT SPLIT은 250점 × 콤보입니다. 거리 점수는 미터당 0.4점입니다.
- 콤보는 근접 추월 후 5초 유지되며 최대 10배입니다. 근접 추월은 부스트 16, PERFECT는 22를 충전합니다.
- 부스트는 최대 100, 시작 35이며 초당 21을 소비합니다. 20 미만에서는 초당 1.5를 자연 충전합니다. 완전히 소진되면 버튼을 놓았다 다시 눌러야 발동합니다.
- 내구도는 3입니다. 충돌 시 하나를 잃고 콤보가 끊어지며 부스트 20을 잃습니다. 2.2초간 추가 충돌에서 보호되며 이때 지나친 차량으로 근접 보상을 얻을 수 없습니다.
- 2km·4km 지점에서 내구도 1 회복(최대 3), 부스트 20 충전. 6km 완주 시 2,500 + 남은 내구도 × 500점을 더합니다.
- 최고 점수, 최고 주행 거리, 소리 설정은 현재 브라우저에 저장됩니다. 저장이 차단돼도 플레이할 수 있습니다.

## 구성과 실행

- `index.html`, `styles.css`: 시작·주행·일시정지·결과 화면과 반응형 조작 UI.
- `core.mjs`: 120Hz 고정 시간 간격의 주행, 교통, 충돌, 점수 규칙. 화면 픽셀과 분리됩니다.
- `renderer.mjs`: 원근 도로, 세 구간, 자동차와 라이더를 Canvas로 직접 그립니다. 고정 배경을 캐시하며 화면 배율은 최대 2배입니다.
- `audio.mjs`: Web Audio로 엔진·바람·추월·부스트·충돌 소리를 만듭니다. 오디오는 사용자 입력 후 시작합니다.
- `app.mjs`: 입력, 저장, 화면 상태 연결. 키 해제·포커스 상실·터치 취소를 처리합니다.
- `racing-game.html`: 예전 주소에서 새 게임으로 이동합니다. 이전 이미지 파일은 호환·원본 보존 목적으로 남아 있으며 새 실행본에서는 사용하지 않습니다.

별도 설치나 빌드가 없는 정적 웹 게임입니다. 저장소 루트에서 `python3 -m http.server 8877` 실행 후 `/games/bike_game/`를 엽니다. 웹 글꼴을 불러오지 못해도 시스템 글꼴로 플레이됩니다.

```sh
node --test games/bike_game/tests/core.test.mjs
node games/bike_game/tests/drive-check.mjs
```

브라우저 화면 검사와 자동 주행은 실제 휴대폰 터치감·장시간 성능이나 사람의 난이도 평가를 대신하지 않습니다. 기존 버전은 Git 이력에 보존됩니다.
