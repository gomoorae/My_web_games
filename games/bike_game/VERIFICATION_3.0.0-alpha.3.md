# 조향·커브·소리 수정 검증 · 2026-10-14

## 변경과 검사

`node --test games/bike_game/tests/core.test.mjs games/bike_game/tests/audio.test.mjs`: 39개 통과.

- 도로 화면과 물리가 같은 곡률 함수를 사용하며, 우커브에는 왼쪽 바깥으로, 좌커브에는 오른쪽 바깥으로 흐릅니다.
- 차량이 없는 도로에서도 중앙 무입력은 첫 커브에서 종료됩니다. 커브에 맞춰 조향하는 입력은 6km 이후에도 계속 달릴 수 있습니다.
- 중앙선을 가로지르는 차선 변경이 실제 충돌로 이어지는 개별 사례를 검사했습니다.
- 100ms 오른쪽 입력: 입력 종료 시 0.0411, 손을 떼고 200ms 뒤 최종 0.0585만큼 이동합니다(도로 반폭을 1로 한 좌표). 이전 즉시 속도 방식의 0.135보다 최종 이동이 약 57% 짧습니다.
- 손을 뗀 뒤 조향으로 추가 이동하는 거리를 제한했고, 반대 입력·일시정지·재시작 시 남은 움직임을 확인했습니다.
- 오디오 초기화와 계속 달리기만으로는 발진기나 소음 재생 노드를 만들지 않습니다. 일반 추월도 무음입니다.
- 근접·충돌 효과음은 모두 0.2초 이내에 종료되며, 중복 보상에 소리가 과도하게 겹치지 않도록 제한합니다. 일시정지·음소거는 남은 음을 정리합니다.
