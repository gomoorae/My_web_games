# 바이크 칼치기 3.0.0 정식판 검증

검증일: 2026-10-14. 정식판은 직전 버전에서 확인한 교통 흐름, 조향, 커브, 점수, 효과음 규칙을 유지합니다. 시작 화면의 시험판 표시와 파일 버전을 `3.0.0`으로 정리했습니다. 기록 저장 키도 유지합니다.

## 마무리 수정

- 568 × 320 등 낮은 가로 화면에서 시작 화면 상단이 잘리던 배치를 수정했습니다. 시작·재도전 버튼을 화면 안에 배치했습니다.
- 충돌 안내의 한국어 조사를 차종에 맞게 표시합니다. 예: 버스와 / 트럭과.
- 이전 검증 문서는 이력으로 남깁니다. 현재 게임은 시험판 모듈 주소를 참조하지 않습니다.

## 게임 규칙과 장시간 교통

`node --test games/bike_game/tests/core.test.mjs games/bike_game/tests/audio.test.mjs`: 40개 통과.

- 조향의 시작·해제·반전, 커브 방향, 서로 다른 프레임 속도, 긴 프레임 간격, 충돌·보상, 재시작, 일시정지, 유한한 효과음을 검사했습니다.
- 차종 4개 × 회전각 11개 × 앞뒤 위치 33개 × 바이크 위치 41개, 총 59,532가지 충돌 조건을 별도의 다각형 교차 계산과 비교했습니다. 모두 일치했습니다.

`node games/bike_game/tests/drive-check.mjs --soak`: 64개 배치 × 600초, 총 10시간 40분의 교통 시뮬레이션 통과.

- 차선 변경 14,770회 시작, 14,739회 완료, 검사 종료 시 진행 중 31회. 시작한 변경이 사라지거나 중단된 경우가 없었습니다.
- 차량끼리 차체가 겹치지 않았으며, 일반 주행은 차선 중앙을 유지했습니다. 관찰된 최대 차량 수는 23대였습니다.
- 0.1초 간격의 도로 횡단면 384,000개에서 바이크가 들어갈 공간이 전혀 없는 순간은 발견되지 않았습니다. 이는 공간의 존재 검사이며, 그 공간까지 사람의 반응 속도로 이동할 수 있다는 보증은 아닙니다.
- 좌·중앙·우의 무입력 72회 모두 90초 이내 종료. 커브만 보정하며 중앙을 고수한 48회도 모두 120초 이내 종료했습니다.

`node games/bike_game/tests/route-check.mjs`: 고정 배치 12개 모두 120초 생존 경로 탐색 및 실제 엔진 재생 통과.

- 각 경로에서 224~236대를 추월하고 차선 변경 44~50회를 통과했습니다.
- 탐색은 차량의 미래 움직임을 모두 알고 0.1초 단위로 입력을 선택합니다. 회피 가능한 경로가 있는지 확인하는 검사이며 사람의 성공률이나 모든 배치의 공정성을 보증하지 않습니다.
- 사용자는 PC 웹브라우저에서 직접 플레이한 뒤 게임 구성과 재미가 충분하다고 확인했습니다.

## 화면과 사용 흐름

- 브라우저 화면 320 × 568, 390 × 844, 568 × 320, 844 × 390, 1280 × 720에서 제목·시작·효과음 버튼이 화면 안에 표시되고 가로 넘침이 없었습니다.
- 568 × 320에서 충돌 결과와 재도전·처음 화면 버튼을 확인했습니다.
- 키보드 재도전과 일시정지, 계속하기, 화면 크기 변경 후 정지 상태 유지, 화면 조향 버튼의 짧은 입력 후 눌림 해제를 확인했습니다.
- 새로고침 후 최고 기록·최장 시간과 효과음 끄기 설정이 유지됐습니다.

## 렌더링과 검증 범위

- PC 브라우저의 1280 × 720, 배율 2 환경에서 동일한 교통·렌더러를 60초 연속 실행했습니다. 7,202프레임, 50ms를 넘는 프레임 간격 0회, 평균 작업 시간 0.898ms, 95백분위 1.4ms였습니다. 처음 10초와 마지막 10초의 평균은 0.927ms / 0.902ms였습니다.
- PC 브라우저를 390 × 844, 배율 1로 바꾼 60초 검사에서는 7,201프레임, 50ms를 넘는 프레임 간격 0회, 평균 작업 시간 0.656ms, 95백분위 1.1ms였습니다. 처음과 마지막 10초 평균은 0.702ms / 0.623ms였습니다.
- 이 측정은 별도의 로컬 렌더링 부하 화면을 사용합니다. 실제 게임의 점수·충돌 종료를 포함한 사람의 플레이 결과나 휴대폰 성능 측정으로 해석하지 않습니다. 임시 화면은 배포하지 않습니다.
- 실제 휴대폰의 터치감, 기기별 성능·발열, iOS·Android 브라우저의 실기기 호환성은 확인되지 않았습니다. 화면 크기와 버튼 입력 검사를 이와 구분합니다.
- 공개 배포 완료와 파일 일치 여부, 공개 주소의 실행 확인은 배포 후 별도 기록합니다.
