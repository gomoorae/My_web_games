# 무작위 재도전 검증 · 2026-10-14

버전 `3.1.1`에서는 시작과 모든 재도전이 새 차량 배치를 선택합니다. 직전 시드에 0이 아닌 무작위 값을 더하므로 같은 순간에 재시작해도 직전 시드를 재사용하지 않습니다.

- 결과 화면 버튼, 일시정지 버튼, R, 사고 연출·결과 화면의 Space가 모두 동일한 새 시작 함수를 사용합니다.
- 버튼과 키 안내는 ‘재도전’으로 통일하고 ‘같은 배치’ 안내를 제거했습니다.
- 교통 생성·충돌·점수·조향·세로 화면·사고 연출과 기록 저장 키는 유지합니다. 도로 커브 구성은 이 변경의 대상이 아닙니다.
- 내부의 고정 시드 재생 기능은 교통 검사에 계속 사용하며 사용자 재도전과 분리합니다.

`node --test games/bike_game/tests/core.test.mjs games/bike_game/tests/audio.test.mjs games/bike_game/tests/presentation.test.mjs`: 기존 49개 검사 통과.

로컬 브라우저에서 첫 판, R 재도전, 일시정지 후 재도전의 서로 다른 초반 차량 배치를 확인했습니다. Space와 결과 화면 버튼으로 다시 주행할 수 있고, 일시정지·결과 화면 모두 ‘재도전’으로 표시됐습니다. 기존 기록 유지와 브라우저 오류 없음도 확인했습니다.

공개 배포 파일 일치와 공개 주소 동작은 배포 후 별도 검증 기록에 남깁니다. 브라우저 검사는 실제 휴대폰의 터치감·발열 검증을 의미하지 않습니다.
