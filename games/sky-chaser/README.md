## 0.10.1 격추 후 폭탄 회복

- 목숨이 남은 상태에서 격추되면 기존 회복용 P와 함께 B 아이템을 하나 방출합니다. 두 아이템은 반대 방향으로 튀어나오며 0.65초 뒤부터 회수할 수 있습니다.
- B를 회수하면 폭탄이 하나 늘어납니다. 기본 세 목숨에서 재출격 두 번의 B를 모두 회수하면 폭탄을 총 두 개 더 얻습니다. 보유 상한은 기존처럼 다섯 개이며, 가득 찬 상태의 B는 1,000점으로 바뀝니다.
- 피격 후 3초 무적과 파워 감소, 스테이지별 난이도·적 공격·조작·음악·컷씬은 유지합니다. 마지막 게임 오버에는 추가 회복 아이템이 나오지 않습니다.

## 0.10.0 세 스테이지 난이도 흐름 재조정

- 일반 적 수는 보통 1스테이지 98→72, 2스테이지 90→82, 3스테이지 90→77입니다. 3스테이지 쉬움은 83→74입니다. 편대 내 출현 간격을 늘리고 특히 3스테이지 93~98초·123~129초의 겹침을 풀었습니다. 첫 진입 사격은 유지합니다.
- 일반 적의 반복 사격 주기를 1/2/3스테이지 순으로 1.08/0.98/0.90배로 설정합니다. 쉬움은 여기에 1.24배를 적용합니다. 탄속 배율은 1.00/1.12/1.22로 단계적으로 증가하고 쉬움은 72%입니다. 지나간 일반 적은 y=430/450/470 아래에서 사격하지 않고, 한 기의 반복 발사는 3/4/4회로 제한합니다.
- 제미니는 포대 상태와 무관하게 본체탄을 발사합니다. 보통 본체탄 1.08초, 레이저 2.4초의 독립된 주기로 움직이며 본체탄 실제 속도는 224입니다. 한 포대만 남았을 때 일반탄이 사라지던 상태를 제거했습니다. 쉬움 본체탄은 1.65초, 레이저는 3.1초입니다.
- 템페스트도 모든 형태에서 본체 사격을 유지합니다. 2형태의 완전 원형탄은 매 발사마다 틈이 조금 회전하고 실제 속도는 보통 184.8입니다. 3형태는 본체탄 1.1초와 레이저 2.45초가 독립적으로 이어집니다. 레이저 예고와 열린 회피 통로는 유지합니다.
- 볼칸은 본체 사격 1초와 포탄 2.7초를 분리하고 두 포대의 포탄을 0.3초 차이로 발사합니다. 보통 본체탄 실제 속도는 231.8입니다. 포대 파괴는 그 포대의 폭발탄을 취소하지만 본체 사격을 멈추지 않습니다. 쉬움은 본체탄 1.55초, 포탄 3.5초입니다.
- 이그니스는 1·3형태의 본체 사격을 특수 공격과 분리해 공백을 줄였습니다. 가장 포화됐던 2형태는 곡선탄 수와 발사 빈도를 완화했습니다. 1스테이지 기함의 빠른 후반 연사는 조금 늦춰 초반 난이도의 기준으로 삼았습니다.
- 이전에 정한 1·2스테이지 보스 체력은 유지합니다. 뒤 스테이지인데 더 빨리 끝나던 볼칸은 1,250→1,800, 이그니스는 4,200→6,400으로 보완합니다. 플레이어의 이동·피격 판정·기본 사격·차지샷·폭탄 피해·파워업·기록은 그대로입니다. BGM과 그림 32개 파일, 매번 재생하는 컷씬 정책도 보존했습니다.

자동 조작은 사람의 체감 난이도나 클리어 가능성을 증명하지 않습니다. 기본 정책의 연속 출격 12회는 모두 게임 오버였고 그 결과를 그대로 보관했습니다. 입력 위상 ID는 적의 난수 변형이 아닙니다. 추가로 실제 키 입력으로 일반 구간·제미니·템페스트·볼칸·이그니스 구간을 조작하며 정지 후 화면을 확인했습니다. 이 검증은 무적 없는 구간 검사이며 사람이 전 스테이지를 연속 클리어했다는 뜻은 아닙니다. 실물 휴대폰 검증은 포함하지 않습니다. 비교 자료와 수동 조작 기록은 소스의 artifacts/difficulty-v0.10.0에 있습니다.

## 0.9.3 보스 체력·중간 보스 탄막·매번 재생하는 컷씬

## 0.7.6 Shift · Z · X 조작

## 0.7.4 기본 사격 자동화

PC도 출격 카운트다운이 끝나면 기본 사격이 자동으로 계속 나갑니다. 기본 사격을 위해 키를 누르거나 토글을 켤 필요가 없습니다. 이동·Shift 정밀 이동·Z 차지샷·X 폭탄을 조작합니다. 수동 사격 안내와 ON/OFF 토글은 제거하고 **기본 사격 자동** 표시로 바꿨습니다.

## 0.5.1 화면 처리 최적화

- 시작 화면은 일러스트 뒤의 전투 화면을 그리지 않습니다. 일시정지는 한 번만 그린 뒤 반복 작업을 멈춥니다. 게임 오버·클리어는 남은 폭발 연출이 끝난 다음 멈추며, 화면 복귀·크기 변경·재개 시 필요한 장면을 다시 그립니다.

- 빛 번짐·폭발의 불꽃·일반 사격을 재사용 그림으로 저장합니다. 화면 밖 구름과 투명한 수면 반사는 그리지 않고 변하지 않은 HUD 문구는 다시 쓰지 않습니다. 캐시는 최대 64개로 제한합니다.
- 원본 그림 14개와 화면 배치, 전투·스테이지·기록·음향 코드는 버전 주소를 제외하고 0.5.0과 일치합니다. 탄 수, 탄속, 적 체력, 공격 주기, 판정, 파워업 규칙은 동일합니다.
- 로컬 Chromium 검사에서 5초간 시작·일시정지는 화면 그리기와 반복 콜백 모두 0회, 전투는 화면 300회 / 계산 600회였습니다. Windows 실기기의 팬 소음과 GPU 전력은 별도 측정하지 않았습니다.

- 일반 난이도에서 착탄 폭발까지 약 1.75~1.9초, 쉬움은 약 2.1~2.2초를 줍니다. 폭발 반경은 보통 36 / 쉬움 28, 활성 시간은 0.55초입니다. 동시에 존재하는 포탄은 최대 6개입니다. 경고 위치는 이동하는 플레이어를 추적하지 않습니다.
- 보라색 탄은 처음 약 0.9초 동안 휘어지고 이후 직진합니다. 속력은 유지하며 플레이어를 추적하지 않습니다. 초반의 폭격기와 기뢰에서 두 규칙을 배운 뒤 복합 편대가 등장합니다.
- 화로거북 볼칸: 본체 체력 1250, 좌우 포대 각각 180. 포대를 파괴하면 그 포대의 발사와 진행 중인 폭발탄이 멈춥니다. 격추 보상은 P와 폭탄 하나입니다.
- 홍련룡 이그니스: 체력 4200, 외곽 포대 각각 260. 장갑 용광로 → 날개를 펼친 기계룡 → 과열된 심장의 세 단계입니다. 2회의 2.6초 변신에서 탄과 폭발탄이 정리되고 파워 시간이 멈춥니다. 마지막 격추는 열린 날개와 드러난 심장을 그대로 유지한 파편을 사용합니다.
- 천익 섬광은 날아오는 포탄·착탄 대기·폭발 중인 위험 지역까지 제거합니다. 보스 본체와 부품의 합산 피해는 기존과 동일하게 최대 540입니다.
- 새 기록은 `sky-chaser.v3`에 저장합니다. 기존 `v1`, `v2`는 덮어쓰지 않습니다. 2스테이지 연습 기록과 소리·화면 흔들림 설정을 이어받으며, 세 스테이지 연속 기록과 3스테이지 연습 기록을 분리합니다.

## 0.4.2 일반 적 진입 사격

- 일반 적 5종은 화면에 진입해 피격 가능해지는 첫 프레임에 첫 사격을 합니다. 이전에는 피격이 먼저 가능해지고, 더 내려온 뒤에도 1스테이지 1.3초 / 2스테이지 0.9초를 기다렸습니다.
- 피격 시작과 일반 적의 발사 시작이 `ENEMY_ACTIVE_Y = 5`를 함께 사용합니다. 추가 대기 시간은 없으며, 같은 프레임의 일반 사격 판정보다 먼저 초탄을 발사합니다.
- 이후의 발사 주기, 0.4.1의 탄 수 2배, 탄속·체력·움직임은 유지합니다. 보스의 등장 준비와 레이저 예고 시간도 유지합니다.
- 화면 밖, 플레이어와 110픽셀 이내, 천익 섬광 중에는 발사를 억제합니다. 억제된 탄을 여러 번 몰아서 쏘지 않습니다.
- 최대 파워로 적을 따라 사격하는 비교에서 0.4.1은 두 스테이지 × 일반 적 5종 모두 발사 전 격추됐습니다. 0.4.2는 동일한 10가지 상황 모두 진입한 첫 프레임에 발사했습니다.

## 0.4.1 탄막 강화와 레이저 연출 수정

- 파워 상승·유지 시간 갱신·시간 경고·단계 하락의 상단 알림을 제거했습니다. 파워 단계, 남은 시간, 마지막 5초의 게이지 색상은 유지합니다.
- 조준 고정 글자를 제거했습니다. 발사구의 회전 룬과 모이는 입자, 좁혀지는 조준 표시, 예고 광선으로 충전을 표현합니다. 발사 후에는 광원·빛 번짐·내부 흐름·주변 에너지 입자가 함께 움직입니다.
- 예고와 발사의 위치·폭·타이밍은 실제 레이저 판정과 같습니다. 조준 표시는 발사 당시의 지정 위치에 고정되며 일시정지 중에는 모든 움직임이 멈춥니다.
- 템페스트의 격추 이벤트에 마지막 형태를 보존합니다. 최종 동력핵(171 논리 픽셀)만 네 조각으로 분해되고 청록빛 폭발을 내며, 이전 장갑 그림이 잔해로 재등장하지 않습니다.
- 1·2스테이지의 모든 일반 적·중간 보스·보스 탄막을 0.4.0의 정확히 두 배로 늘렸습니다. 기존 탄을 보존하고 탄 사이에 추가 탄을 배치합니다. 탄속·발사 간격·레이저 수는 유지하며 최대 탄 수는 840으로 늘렸습니다.
- 템페스트의 회전 탄막에 추가되는 탄은 예정된 회피 통로를 침범하지 않습니다.

## 0.4.0 뇌운의 협곡과 파워 유지

- 1스테이지 종료 후 목숨·폭탄·파워·유지 시간·점수를 보존해 2스테이지로 진입합니다. 추가 목숨이나 폭탄을 자동 지급하지 않습니다.
- P 획득 시 파워를 한 단계 올리고 유지 시간을 25초로 갱신합니다. 최대 파워에서도 시간이 갱신됩니다. 만료 시 한 단계만 내려가며 다시 25초가 시작됩니다. 1단계 아래로는 내려가지 않습니다.
- 시작 3초 뒤부터 12초 간격으로 P를 보급합니다. 일반 적 격추 수와 무관하며 보스전에도 계속됩니다. 중간 보스의 추가 P와 B 보상은 유지합니다.
- 격추 시 파워 한 단계 감소, 폭발과 함께 회복용 P 방출, 3초 무적. 1단계에서도 P를 하나 떨어뜨립니다. 방출 직후 0.65초간 튀어나온 다음 회수할 수 있습니다.
- 일시정지·스테이지 전환·보스 변신 중에는 파워와 보급 시간이 멈춥니다. 화면 안과 오른쪽 패널에 유지 게이지를 표시하고 마지막 5초에 경고합니다.
- 제미니: 독립 포대 2개, 조준이 고정되는 예고 레이저와 느린 부채꼴 탄. 포대를 파괴하면 해당 레이저가 취소됩니다.
- 템페스트: 체력 3900, 외곽 포대 → 회전하는 빈틈 탄막 → 노출된 동력핵과 공간 분할 레이저. 2회의 2.2초 변신을 강한 공격으로 건너뛸 수 없습니다.
- 레이저는 예고 구간에 피해가 없고, 예고선이 플레이어를 추적하지 않습니다. 천익 섬광은 예고선과 발사된 레이저를 모두 지웁니다.
- 폭탄 피해는 보스 전체에 540을 배분하며 부품마다 중복 적용하지 않습니다. 포대가 남아 있을 때 본체에 60%, 포대에 합계 40%를 줍니다.
- 2스테이지 일반 적은 탄속 +18%, 공격 주기 20% 단축(빈도 +25%), 체력 +15% 올림, 첫 공격 대기 0.9초입니다. 쉬움의 기존 완화도 적용됩니다.
- 파란 협곡 지도가 초당 106 논리 픽셀로 이동합니다. 일반 탄은 분홍·금색, 레이저 예고는 금색, 발사는 청록·흰색으로 구분됩니다.
- 기존 기록과 설정을 저장한 `sky-chaser.v1`은 삭제하거나 덮어쓰지 않습니다. 새 `sky-chaser.v2`에서 연속 출격과 2스테이지 연습 기록을 분리하고, 기존 소리·흔들림 설정을 이어받습니다.

## 0.3.1 루미 크기와 목도리

- 루미의 표시 너비를 86에서 68.8 논리 픽셀로 줄였습니다. 세 비행 자세와 그림자 모두 80% 크기입니다.

- 긴 목도리를 몸체 그림에서 분리했습니다. 목 쪽을 고정하고 끝으로 갈수록 흔들림이 커지는 두 가닥 천으로 그리며, 좌우 이동 방향에 따라 뒤로 흐릅니다.
- 그림체가 바뀌지 않도록 기존 몸체 그림에서 긴 목도리 부분만 수정했습니다. 폭탄 연출에는 기존 그림을 그대로 사용합니다.
- 작은 캐릭터의 총구에 맞춰 사격 시작 위치와 충전 표시를 함께 조정했습니다. 피격 판정과 이동 속도는 유지합니다.

## 0.3.0 속도감·PC 화면·천익 섬광

- 지도가 초당 82 논리 픽셀로 계속 흐릅니다. 물가의 겹친 경계로 반복 구간을 잇고, 먼 구름 43 / 가까운 구름 142 픽셀로 거리감을 만듭니다.

- F 또는 전체화면 버튼으로 브라우저 전체화면을 사용할 수 있습니다.
- 루미 전용 폭탄은 천익 섬광입니다. 인물 일러스트와 거대한 룬 날개가 나타나며 여섯 번의 포격과 마지막 강타를 가합니다.
- 3초 동안 탄을 지우고 무적을 제공합니다. 보스가 전부 맞으면 70×6+120=540 피해입니다. 변신 중인 보스에게는 피해가 들어가지 않습니다.
- 일시정지 중에는 폭탄의 타격 시간도 멈추며, 재시작하면 남은 타격이 취소됩니다.
- 갱신한 코드에는 버전 주소를 적용해 이전 브라우저 캐시와 섞이지 않도록 했습니다.

## 실행

Node 외부 패키지와 빌드 과정 없이 실행됩니다. Python 3 정적 서버를 이용합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:8766/ 을 여세요. ES 모듈을 사용하므로 HTML 파일을 더블클릭하는 방식은 지원하지 않습니다.

```sh
npm test
node tests/playthrough.mjs
```

## 구성

- dist/index.html / style.css / desktop.css: 출격, 조작 안내, HUD, 결과 화면과 PC 세로 전체 높이 배치.
- dist/engine.mjs: DOM과 분리된 전투 규칙. 120Hz 고정 간격으로 실행.
- dist/stages.mjs: 스테이지·출격 코스 구성, 제미니·템페스트 공격과 레이저 충돌.
- dist/forge.mjs / forge-fx.mjs: 3스테이지 편대와 보스, 폭발탄·곡선탄 및 전용 연출.
- dist/records.mjs: 코스별 기록 및 기존 설정 보존.
- dist/art.mjs: 원본 스프라이트의 투명 경계 판독과 렌더링용 이미지 준비.
- dist/render.mjs: Canvas 렌더링. 화면 해상도와 전투 좌표 독립.
- dist/laser-fx.mjs: 고정된 조준 위치와 게임 시간에 맞춘 충전·레이저 연출.
- dist/app.mjs: 실제 입력, 일시정지, 저장, 화면 연결.
- dist/mobile.html / mobile.css / mobile.mjs / mobile-core.mjs: 별도 모바일 조작 시험판과 포인터·배치·설정 처리.
- dist/frame-loop.mjs / canvas-fx.mjs: 유휴 중단, 화면 출력 주기, 내부 픽셀 예산과 반복 광원 캐시.
- dist/audio.mjs: 사용자 출격 입력 이후 활성화되는 Web Audio 음악과 효과음.
- dist/assets: 런타임 에셋. 생성 정보와 프롬프트는 ASSETS.md.
- tests: 충돌/상태 회귀 검사 및 조작만 사용하는 전체 진행 검사.
- .openai/hosting.json: 이 게임의 독립 Sites 배포 정보.

전체 정적 배포물은 dist/입니다. 기존 My_web_games로 옮길 때는 이 디렉터리 내용만 게임의 개별 폴더로 복사하면 됩니다. 게임 목록은 스카이 체이서 항목만 통합하고 다른 게임의 파일과 항목은 유지합니다.

## 검증 범위
