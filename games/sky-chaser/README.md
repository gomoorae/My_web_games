## 0.8.0 빼앗긴 바람

공중해적단이 항로를 지키는 룬 등대의 동력핵을 훔쳤습니다. 루미는 도주하는 수송선을 추격해 아이언 레이븐을 뚫고, 템페스트가 만든 인공 폭풍을 걷어 내며, 홍련의 조선소에서 강제 기동된 이그니스를 멈춥니다. 되찾은 바람의 심장을 항구로 돌려보내며 이야기가 끝납니다.

- 연속 출격에 오프닝 3장면(17초), 2·3스테이지 진입 각 1장면(6.5초), 각 최종 보스 등장 1장면(4.2~4.5초), 엔딩 3장면(18초)을 연결했습니다. 새 이야기 일러스트 3장, 기존 그림과 보스의 첫 형태, 짧은 합성 효과음과 느린 화면 이동을 사용합니다.
- 모든 장면에 **건너뛰기**, **다음**, **자동 넘김 멈춤** 버튼이 있습니다. PC는 Esc로 현재 이야기 묶음을 건너뛰고 Enter/Space로 선택한 버튼을 실행합니다. 키를 길게 눌러도 장면이 연달아 넘어가거나 전투 차지샷·폭탄으로 이어지지 않습니다.
- 기본값은 **본 이야기 자동 건너뛰기**입니다. 끝까지 보거나 직접 건너뛴 묶음은 이후 출격에서 생략합니다. 시작 화면의 **이야기 · 빼앗긴 바람**에서 이 설정을 끄거나 열린 장면을 다시 볼 수 있습니다. 엔딩은 연속 출격 클리어 후 열립니다. 2·3스테이지 연습은 이야기를 생략하며 엔딩을 열지 않습니다.
- 이야기 중 전투 시간·파워 유지 시간·입력·전투 음악을 멈춥니다. 다른 창으로 이동하거나 화면 크기가 바뀌면 자동 넘김도 멈추고 **계속 보기**로 재개합니다. PC·모바일 점수와 감도 저장은 보존하며 이야기 진행만 별도 `sky-chaser.story.v1`에 저장합니다. 같은 브라우저의 PC·모바일 화면은 이야기 진행을 공유합니다.
- 기존 전투 규칙, 적 공격과 난이도, 화면 크기, 루미 크기, 자동 사격, Shift·Z·X 조작은 유지합니다. 이야기 화면에서는 전투 반복 그리기를 중단하고 한 장면에 한 번의 타이머만 사용합니다.

140개 자동 검사가 통과했습니다. 브라우저에서 PC·모바일의 오프닝 → 세 보스·스테이지 전환 → 엔딩 → 기록 화면을 확인했습니다. 반복 출격 생략, 수동 다시 보기, 연습 모드 생략과 엔딩 잠금, 키 입력 격리, 화면 이탈 중 일시정지, 320×568·393×760·768×650·844×390 화면 배치를 확인했습니다. 실물 갤럭시 기기의 터치감·음향·장시간 발열 검증은 포함하지 않습니다.

## 0.7.6 Shift · Z · X

차지샷은 **Z**입니다. **Shift 정밀 이동 · Z 차지샷 · X 폭탄**을 사용하세요. 게이지가 가득 차면 Z를 한 번 눌러 발사합니다. 자동 사격은 계속되며 Z를 길게 눌러도 반복 발사되지 않습니다. 충전 완료 표시와 조작 안내도 Z로 바꿨습니다.

## 0.7.5 일반 이동 100% · 정밀 이동 70%

PC의 기본 이동 감도는 100%입니다. Shift를 누르면 선택한 일반 이동 속도의 70%로 움직입니다. 이전 기본값 90%가 저장되어 있으면 100%로 갱신하고, 이후 직접 선택한 감도는 계속 저장합니다.

## 0.7.4 기본 사격 자동

출격하면 기본 사격이 자동으로 이어집니다. 수동 사격 안내와 자동사격 ON/OFF 버튼을 없앴습니다. Shift로 정밀 이동하는 중에도 기본 사격은 계속되며, 일시정지·설정 중에는 멈춥니다. 공격력과 연사 속도는 그대로입니다.

## 0.7.3 PC 감도와 루미 크기

PC에서 상단 **설정 → 키보드 이동 감도**를 열어 50~120%로 조절하세요. 기본은 100%입니다. 방향키/WASD와 Shift 정밀 이동에 같은 설정 배율을 적용하고, 정밀 이동은 일반 이동의 70% 속도입니다. 감도를 자동 저장합니다. 설정 중에는 비행을 멈추고 닫은 뒤 직접 재개합니다. 모바일 감도 1.1은 유지합니다.

루미의 화면 크기와 실제 피격 반경을 각각 10% 줄였습니다. PC·모바일 모두 적용하며 목도리와 총구·차지 표시도 크기에 맞췄습니다. 공격력과 적들의 공격은 그대로입니다.

## 0.7.2 폭발탄 + 기본 탄환 · 홈페이지 버튼

3스테이지 폭격기는 부채꼴 탄환 10발과 폭발탄을 함께 쏩니다. 화로거북 볼칸도 매 공격마다 조준탄과 폭발탄을 병행합니다. 폭발탄 발사 간격·위력과 1·2스테이지, 이그니스의 공격은 유지합니다.

모바일에서 일시정지한 뒤 **그만하고 홈페이지로**를 누르면 게임 사이트로 돌아갑니다. 게임 오버·클리어 화면에서도 같은 버튼을 사용할 수 있습니다. 기존 코스·난이도별 기록과 감도 1.1, 폴드 화면 대응은 유지합니다.

0.7.2의 자동 조작에서는 쉬움은 이그니스 전투까지 진행한 뒤 198.23초에, 보통은 141.54초에 게임 오버했습니다. 자동 조작의 클리어 여부는 사람의 체감 난이도를 대신하지 않습니다.

## 0.6.1 보스와 배경 개선

템페스트 두 번째 형태는 큰 빈 구간 없이 원 전체에 탄을 쏩니다. 보스와 거리를 두면 탄 사이 간격이 넓어집니다. 이그니스는 플레이어를 따라 조준하는 대신 전장 여러 곳에 폭발탄을 차례로 뿌리고, 그동안 부채꼴 탄과 곡선탄도 발사합니다. 포대 파괴나 천익 섬광은 발사 대기 중인 폭발탄도 취소합니다.

항구 배경은 색감과 대비를 낮추고 넓은 구름층을 깔아 루미와 탄환을 구분하기 쉽게 했습니다. 배경 속도와 화면 크기는 유지합니다. 1스테이지 보스와 기존 일반 구간, 2·3스테이지 배경은 그대로입니다.

## 0.6.0 적중 차지샷과 폭발탄

일반탄·유도 보조탄의 실제 적중 피해 240을 모으면 관통 차지샷이 준비됩니다. Z 또는 활성화된 터치 버튼을 한 번 누르면 발사하며 기본 사격을 멈출 필요가 없습니다. 일시정지·스테이지 이동 때 충전량을 유지하고, 격추·새 출격 때 초기화합니다.

## 0.5.1 최적화

시작·일시정지는 화면이 바뀔 때만 그리며, 종료 시 남은 폭발 연출이 끝나면 반복 작업을 멈춥니다. 플레이 화면 출력은 60fps, 전투 계산은 기존 120Hz입니다. PC 화면 높이와 그림·탄 수·탄속·적 체력·판정을 유지합니다. 큰 고해상도 화면의 내부 그림만 최대 1200×1800으로 제한하고 광원·폭발·사격 그림을 재사용합니다.
