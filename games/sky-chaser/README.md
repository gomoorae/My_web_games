# 스카이 체이서 · SKY CHASER

0.7.5 · 2026-10-17

[PC·모바일에서 플레이](https://gomoorae.github.io/My_web_games/games/sky-chaser/?v=0.7.5) · [게임 목록](https://gomoorae.github.io/My_web_games/)

휴대폰에서는 모바일 화면이 자동으로 열립니다. 0.7.1은 폴드의 넓은 화면을 가로로 잘못 판단해 진입을 막던 문제를 수정했습니다. 세로 안내가 뜨더라도 **이 화면으로 플레이**로 진행할 수 있습니다. 왼쪽 패드를 밀어 이동하고 오른쪽 버튼으로 차지샷과 폭탄을 사용하세요. 기본 사격은 자동이며 감도 기본값은 1.1입니다. 정밀 이동 버튼을 없애고 패드를 넓혔습니다. 설정에서 감도와 좌우 배치를 조절할 수 있습니다. PC 시작 화면과 모바일 설정에서 조작 방식을 직접 바꿀 수도 있습니다.

시험판의 코스·난이도별 기록과 소리·좌우 배치를 이어받습니다. 이전 기본 감도 1.3은 1.1로 바꾸며 그 외 조절 값은 유지합니다. PC 기록은 별도 저장합니다. 이전 시험판 링크도 계속 사용할 수 있습니다. 갤럭시 크롬의 사용자 플레이 피드백을 반영했고 장시간 발열·다른 기종의 확인은 별도 범위입니다.

루미와 해풍의 항구, 뇌운의 협곡, 홍련의 조선소를 돌파하는 세로 슈팅입니다. 쉬움/보통을 선택할 수 있습니다. 연속 출격은 남은 목숨·파워·폭탄을 이어가며, 2스테이지 또는 3스테이지 연습은 목숨 3·파워 3·폭탄 3으로 시작합니다.

PC·모바일 모두 기본 사격은 자동입니다. 사격 버튼 없이 이동·정밀 이동·차지샷·폭탄을 조작하세요. P는 파워를 한 단계 높이고 유지 시간을 25초로 갱신합니다. 최대 단계에서도 시간이 갱신되며, 만료되면 한 단계씩 내려갑니다. 기본 화력은 유지됩니다. 보스전에도 P가 보급되고 격추 시 회복용 P를 방출합니다. B는 폭탄 보급입니다.

## 세 스테이지

- 해풍의 항구: 철갑 순찰정과 두 형태의 아이언 레이븐.
- 뇌운의 협곡: 포대를 파괴할 수 있는 제미니와 세 단계로 변신하는 템페스트. 레이저 예고선은 표시된 자리에서 고정됩니다.
- 홍련의 조선소: 화로거북 볼칸과 홍련룡 이그니스. 주황색 포탄은 사격으로 요격하세요. 방치하면 넓은 범위로 폭발하며 터지기 전에는 반경이 보이지 않습니다. 보라색 탄은 처음에 휘어지다가 직진합니다. 이그니스는 봉인 장갑을 벗고 날개를 펼친 뒤 과열된 심장을 드러냅니다.

기본 적의 강화된 탄막과 진입 즉시 사격은 그대로입니다. 포탄은 천익 섬광으로도 제거할 수 있으며 마지막 보스 격추는 최종 형태의 날개와 심장을 유지합니다.

기존 1·2스테이지 기록은 삭제하지 않습니다. 기존 2스테이지 연습 기록과 설정은 이어받고, 세 스테이지 연속 기록 및 3스테이지 연습 기록을 별도로 저장합니다. 게임 그림은 오리지널 생성 에셋이며 음악과 효과음은 Web Audio 합성음입니다.

130개 검사가 통과합니다. 모바일 입력·자동 진입·설정과 기록 이전을 추가로 검사했습니다. 원형탄의 간격, 시차 발사·폭발, 발사 대기의 일시정지와 취소, 기존 차지샷·판정·출력 최적화를 검사했습니다. 별도로 시작한 두 보스전은 자동 조작에서 쉬움·보통 모두 클리어했습니다. 0.6.1 당시 3스테이지 전체는 쉬움에서 클리어했고 보통에서는 게임 오버했습니다. 자동 조작은 실제 사람의 체감 난이도나 휴대폰 검증을 대신하지 않습니다.

## 0.7.5 일반 이동 100% · 정밀 이동 70%

PC의 기본 이동 감도는 100%입니다. Shift를 누르면 선택한 일반 이동 속도의 70%로 움직입니다. 이전 기본값 90%가 저장되어 있으면 100%로 갱신하고, 이후 직접 선택한 감도는 계속 저장합니다.

## 0.7.4 기본 사격 자동

출격하면 기본 사격이 자동으로 이어집니다. PC의 Z 키 안내와 자동사격 ON/OFF 버튼을 없앴습니다. Shift로 정밀 이동하는 중에도 기본 사격은 계속되며, 일시정지·설정 중에는 멈춥니다. 공격력과 연사 속도는 그대로입니다.

## 0.7.3 PC 감도와 루미 크기

PC에서 상단 **설정 → 키보드 이동 감도**를 열어 50~120%로 조절하세요. 기본은 100%입니다. 방향키/WASD와 Shift 정밀 이동에 같은 설정 배율을 적용하고, 정밀 이동은 일반 이동의 70% 속도입니다. 감도를 자동 저장합니다. 설정 중에는 비행을 멈추고 닫은 뒤 직접 재개합니다. 모바일 감도 1.1은 유지합니다.

루미의 화면 크기와 실제 피격 반경을 각각 10% 줄였습니다. PC·모바일 모두 적용하며 목도리와 총구·차지 표시도 크기에 맞췄습니다. 공격력과 적들의 공격은 그대로입니다.

## 0.7.2 폭발탄 + 기본 탄환 · 홈페이지 버튼

3스테이지 폭격기는 부채꼴 탄환 10발과 폭발탄을 함께 쏩니다. 화로거북 볼칸도 매 공격마다 조준탄과 폭발탄을 병행합니다. 폭발탄 발사 간격·위력과 1·2스테이지, 이그니스의 공격은 유지합니다.

모바일에서 일시정지한 뒤 **그만하고 홈페이지로**를 누르면 게임 사이트로 돌아갑니다. 게임 오버·클리어 화면에서도 같은 버튼을 사용할 수 있습니다. 기존 코스·난이도별 기록과 감도 1.1, 폴드 화면 대응은 유지합니다.

0.7.2의 자동 조작에서는 쉬움은 이그니스 전투까지 진행한 뒤 198.23초에, 보통은 141.54초에 게임 오버했습니다. 자동 조작의 클리어 여부는 사람의 체감 난이도를 대신하지 않습니다.

## 0.6.1 보스와 배경 개선

템페스트 두 번째 형태는 큰 빈 구간 없이 원 전체에 탄을 쏩니다. 보스와 거리를 두면 탄 사이 간격이 넓어집니다. 이그니스는 플레이어를 따라 조준하는 대신 전장 여러 곳에 폭발탄을 차례로 뿌리고, 그동안 부채꼴 탄과 곡선탄도 발사합니다. 포대 파괴나 천익 섬광은 발사 대기 중인 폭발탄도 취소합니다.

항구 배경은 색감과 대비를 낮추고 넓은 구름층을 깔아 루미와 탄환을 구분하기 쉽게 했습니다. 배경 속도와 화면 크기는 유지합니다. 1스테이지 보스와 기존 일반 구간, 2·3스테이지 배경은 그대로입니다.

## 0.6.0 적중 차지샷과 폭발탄

일반탄·유도 보조탄의 실제 적중 피해 240을 모으면 관통 차지샷이 준비됩니다. C 또는 활성화된 터치 버튼을 한 번 누르면 발사하며 기본 사격을 멈출 필요가 없습니다. 일시정지·스테이지 이동 때 충전량을 유지하고, 격추·새 출격 때 초기화합니다.

3스테이지 폭발탄 반경은 보통 90 / 쉬움 70으로 커졌습니다. 기존 반경의 2.5배입니다. 바닥의 사전 범위 표시는 없애고 실제 폭발 중에만 범위를 보여줍니다. 요격 체력과 폭발까지의 시간은 유지합니다. 스테이지 전환 카드에는 번호와 이름만 표시합니다.

## 0.5.1 최적화

시작·일시정지는 화면이 바뀔 때만 그리며, 종료 시 남은 폭발 연출이 끝나면 반복 작업을 멈춥니다. 플레이 화면 출력은 60fps, 전투 계산은 기존 120Hz입니다. PC 화면 높이와 그림·탄 수·탄속·적 체력·판정을 유지합니다. 큰 고해상도 화면의 내부 그림만 최대 1200×1800으로 제한하고 광원·폭발·사격 그림을 재사용합니다.

로컬 Chromium에서 5초간 시작·일시정지·게임 오버의 반복 그리기 0회, 플레이 중 화면 출력 300회 / 전투 계산 600회를 확인했습니다. Windows 실기기의 팬 소음·소비 전력은 직접 측정하지 않았습니다.
