# 스카이 체이서 · SKY CHASER

0.2.0 · 2026-10-15

[PC에서 플레이](https://gomoorae.github.io/My_web_games/games/sky-chaser/) · [게임 목록](https://gomoorae.github.io/My_web_games/)

룬 사수 루미가 해풍의 항구를 지나 해적 기함 아이언 레이븐을 추격하는 세로 슈팅입니다. 약 3분짜리 1스테이지, 일반 적 5종, 중간 보스와 두 형태의 최종 보스가 있습니다.

| 키 | 조작 |
| --- | --- |
| 방향키 / WASD | 이동 |
| Z | 연속 사격 |
| C | 길게 누른 뒤 떼면 차지샷 |
| X | 폭탄: 탄 제거, 광역 피해, 잠깐 무적 |
| Shift | 저속 이동과 피격점 표시 |
| Esc | 일시정지 / 계속 |

오른쪽 조작 안내에서 자동사격을 켤 수 있습니다. P는 공격 강화, B는 폭탄 보급입니다. 최고 기록은 난이도별로 이 브라우저에 저장합니다.

0.2.0은 루미의 비행 자세, 적 편대, 항구 지도, 보스 장갑 분리와 날개 전개, 폭발·그림자·충전 효과를 개선한 버전입니다. 그림은 이 게임을 위해 제작한 오리지널 생성 에셋이고 음악과 효과음은 Web Audio 합성음입니다.

PC 브라우저를 기준으로 확인했습니다. 휴대폰에는 드래그·차지·폭탄 버튼을 제공하지만 실제 휴대폰의 조작감과 성능은 아직 확인하지 않았습니다.
