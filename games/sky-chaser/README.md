# 스카이 체이서 · SKY CHASER

0.5.1 · 2026-10-16

[PC에서 플레이](https://gomoorae.github.io/My_web_games/games/sky-chaser/?v=0.5.1) · [게임 목록](https://gomoorae.github.io/My_web_games/)

루미와 해풍의 항구, 뇌운의 협곡, 홍련의 조선소를 돌파하는 세로 슈팅입니다. 쉬움/보통을 선택할 수 있습니다. 연속 출격은 남은 목숨·파워·폭탄을 이어가며, 2스테이지 또는 3스테이지 연습은 목숨 3·파워 3·폭탄 3으로 시작합니다.

| 키 | 조작 |
| --- | --- |
| 방향키 / WASD | 이동 |
| Z | 연속 사격 |
| C | 길게 누른 뒤 떼면 관통 차지샷 |
| X | 천익 섬광: 룬 포격, 탄·레이저·폭발탄 제거, 무적 |
| Shift | 저속 이동과 피격점 표시 |
| Esc | 일시정지 / 계속 |
| F | 전체화면 / 화면 복귀 |

자동사격은 오른쪽 조작 안내에서 켤 수 있습니다. P는 파워를 한 단계 높이고 유지 시간을 25초로 갱신합니다. 최대 단계에서도 시간이 갱신되며, 만료되면 한 단계씩 내려갑니다. 기본 화력은 유지됩니다. 보스전에도 P가 보급되고 격추 시 회복용 P를 방출합니다. B는 폭탄 보급입니다.

## 세 스테이지

- 해풍의 항구: 철갑 순찰정과 두 형태의 아이언 레이븐.
- 뇌운의 협곡: 포대를 파괴할 수 있는 제미니와 세 단계로 변신하는 템페스트. 레이저 예고선은 표시된 자리에서 고정됩니다.
- 홍련의 조선소: 화로거북 볼칸과 홍련룡 이그니스. 주황색 포탄은 사격으로 요격하거나 표시된 폭발 원 밖으로 이동해 피하세요. 보라색 탄은 처음에 휘어지다가 직진합니다. 이그니스는 봉인 장갑을 벗고 날개를 펼친 뒤 과열된 심장을 드러냅니다.

1·2스테이지의 탄 수 두 배와 진입 즉시 사격은 그대로입니다. 포탄은 천익 섬광으로도 제거할 수 있으며 마지막 보스 격추는 최종 형태의 날개와 심장을 유지합니다.

기존 1·2스테이지 기록은 삭제하지 않습니다. 기존 2스테이지 연습 기록과 설정은 이어받고, 세 스테이지 연속 기록 및 3스테이지 연습 기록을 별도로 저장합니다. 게임 그림은 오리지널 생성 에셋이며 음악과 효과음은 Web Audio 합성음입니다.

68개 규칙·화면 주기 검사, 기존 전투 기록 보존, 새 그래픽과 화면 배치를 확인했습니다. 자동 조작은 3스테이지 쉬움을 약 209초에 클리어했으며 보통 전체 진행에서는 게임 오버했습니다. 별도로 시작한 보스전은 쉬움·보통 모두 세 형태를 거쳐 클리어했습니다. 자동 조작 결과와 실제 휴대폰의 조작감·성능 검증은 구분합니다.

## 0.5.1 최적화

시작·일시정지는 화면이 바뀔 때만 그리며, 종료 시 남은 폭발 연출이 끝나면 반복 작업을 멈춥니다. 플레이 화면 출력은 60fps, 전투 계산은 기존 120Hz입니다. PC 화면 높이와 그림·탄 수·탄속·적 체력·판정을 유지합니다. 큰 고해상도 화면의 내부 그림만 최대 1200×1800으로 제한하고 광원·폭발·사격 그림을 재사용합니다.

로컬 Chromium에서 5초간 시작·일시정지·게임 오버의 반복 그리기 0회, 플레이 중 화면 출력 300회 / 전투 계산 600회를 확인했습니다. Windows 실기기의 팬 소음·소비 전력은 직접 측정하지 않았습니다.
