# 별냠 · Star Munch

별 하나를 먹고 크게 도약해 다음 별로 건너가는 PC 우선 2D 게임. **0.4.0**, 2026-10-13.

## 바로 플레이

공개 게임: **https://gomoorae.github.io/My_web_games/games/star-munch/**

`build/별냠.html`을 브라우저로 열면 됩니다. 그림과 소리가 모두 포함되어 있어 설치나 인터넷 연결이 필요하지 않습니다.

소스 화면은 프로젝트 폴더에서 다음 명령으로 열 수 있습니다.

```sh
python3 scripts/serve.py
```

주소: http://127.0.0.1:8868/ — 서버는 이 컴퓨터에서만 접속할 수 있습니다.

## 조작과 규칙

| 조작 | 행동 |
| --- | --- |
| A / D, ← / → | 좌우 이동 |
| Space | 충전 도약 |
| Esc | 일시정지 / 계속하기 |
| R | 다시 시작 |
| 터치 | 게임 화면의 왼쪽·오른쪽 절반을 눌러 이동합니다. 양쪽을 함께 누르면 도약하며, 하단 충전 표시를 직접 눌러도 됩니다. |

- 화면 위·가운데·아래 어디서든 해당 절반을 누르면 최대 방향 입력을 보냅니다. 손을 떼면 입력을 해제하며, 한 손가락을 반대쪽으로 옮겨 방향을 바꿀 수도 있습니다.
- 이동하면서 반대쪽도 누르면 먼저 누른 방향을 유지한 채 도약합니다. 방향 전환 중 0.1초 미만의 짧은 겹침은 도약하지 않습니다. 양쪽을 계속 누르고 있어도 한 번만 발동하며, 한쪽을 뗐다 다시 누르면 다음 도약을 사용할 수 있습니다. 충전이 부족하거나 부스트 중일 때 입력한 도약은 나중에 자동 발동하지 않습니다.
- 일반 구간에서는 흩어진 별 하나를 먹을 때마다 크게 도약합니다. 상승, 정점, 낙하 중에 다음 별을 골라 좌우로 이동합니다. 화면 아래로 떨어지면 비행이 끝납니다.
- 도약은 한 번 충전된 상태로 시작하며, 충전 게이지 8칸을 채우면 다시 사용할 수 있습니다.
- 별똥별은 2.25초 동안 같은 하늘에서 빠르게 상승하는 부스트를 발동합니다. 기존 별과 장애물은 그대로 이어집니다. 부스트 중에는 먹구름·운석·위성 잔해를 뚫을 수 있습니다.
- 촘촘한 별줄은 캐릭터 옆쪽에서 시작해 완만하게 휘어집니다. 좌우로 직접 이동해 닿은 별만 수집합니다. 별이 끌려오거나 캐릭터가 자동으로 별줄에 맞춰지지 않습니다.
- 부스트가 끝나면 상승 여력과 짧은 충돌 보호 시간으로 기존 일반 별에 이어서 도약합니다. 화면이나 코스를 다시 만들지 않습니다. 작은 별줄의 별은 보상만 주며, 부스트 시간이나 일반 도약을 연장하지 않습니다.
- 아이템은 별똥별 부스트와 보호막 두 가지입니다. 보호막은 장애물 충돌을 한 번 막습니다.
- 보호막을 얻을 때에도 다시 도약하므로 상승 흐름이 끊기지 않습니다.
- 작은 별은 별 1개 값과 도약 1칸, 큰 별은 별 3개 값과 도약 3칸을 줍니다. 충전량은 최대 8칸이며, 큰 별로 충전이 가득 차도 충전 완료 알림이 한 번 나옵니다.
- 점수는 `최고 도달 높이 × 10 + 모은 별 × 15`입니다.
- 최고 높이·점수와 소리 설정은 해당 브라우저에 저장합니다. 저장을 막은 브라우저에서도 플레이할 수 있습니다.
- 다른 창이나 탭으로 이동하면 자동으로 일시정지합니다.

## 구현 기준

캐릭터는 승인된 별 토끼 그림과 12개 자세를 사용합니다. 좌우 입력은 이동·방향·기울기만 바꾸며 도약·낙하·부스트 자세를 덮어쓰지 않습니다. 부스트 도중 Space를 눌러도 부스트나 남은 도약 충전이 취소되지 않습니다.

물리는 1/120초 간격으로 갱신합니다. 일반 도약의 상승 속도는 760, 중력은 1,100입니다. 별 하나로 약 260만큼 올라가며 약 0.69초 후 정점을 지납니다. 주 경로의 높이 차이는 100~232, 좌우 차이는 대체로 85~260입니다. 중간 거리를 중심으로 가까우면서 높은 별, 낮고 먼 별을 섞습니다. 수치는 가로 480, 세로 720인 논리 화면 기준입니다.

3~4번의 도약 흐름을 묶어 같은 방향으로 이어 가기와 방향 전환을 섞습니다. 한 높이에는 보통 1~2개, 드물게 3개의 별을 놓고 큰 별은 주 경로와 선택 경로 모두에 등장합니다. 각 선택지에 별도의 다음 경로를 연결하며, 어느 별에서든 충전 도약 없이 이어 갈 수 있게 합니다. 왼쪽 이동 중·정지·오른쪽 이동 중의 출발 속도를 각각 검사하고, 장애물은 두 번 이상의 다음 도약과 왕복 범위를 고려해 배치합니다. 카메라는 상승을 조금 늦게 따라가 각 도약의 움직임이 화면에 드러나게 합니다.

| 높이 | 장애물 밀도 상한 | 특징 |
| --- | --- | --- |
| 0~150m | 한 화면 1개 | 처음 80m는 장애물 없이 조작 익히기 |
| 150~500m | 한 화면 2개 | 직접 접근하는 길을 막는 정지 먹구름 |
| 500~1,000m | 한 화면 3개 | 천천히 왕복하는 먹구름 |
| 1,000m 이상 | 한 화면 5개 | 높이에 맞는 장애물과 다양한 왕복 경로 |

실제 개수는 무작위 배치와 통과 공간에 따라 달라지며, 평균 밀도는 높이와 함께 증가합니다. 부스트 종료 후에는 1.5초 동안 충돌을 보호합니다.

## 하늘에서 우주까지

| 높이 | 환경 | 장애물 |
| --- | --- | --- |
| 0~500m | 푸른 하늘과 햇빛 | 먹구름 |
| 500~2,000m | 아래로 멀어지는 구름바다 | 먹구름, 왕복하는 구름 |
| 2,000~5,000m | 깊은 푸른 상공, 점점 옅어지는 구름 | 이동하는 먹구름 |
| 5,000~10,000m | 우주 문턱, 별빛과 행성의 가장자리 | 먹구름에서 운석으로 점진적으로 전환 |
| 10,000m 이상 | 별빛 우주, 행성·성운 | 운석과 천천히 움직이는 위성 잔해 |

배경색·햇빛·구름·별빛·행성은 높이에 따라 부드럽게 전환합니다. 부스트 중에도 같은 코스에서 전환합니다. 장식용 별은 작고 희미한 점으로, 수집할 별은 금빛 별 모양으로 구별합니다. 운석은 5,000m부터 서서히 섞이고 8,800m부터 구름을 완전히 대체합니다. 위성 잔해는 10,300m부터 등장하며 최대 좌우 속도는 초당 22 논리 단위입니다. 높은 구간에서도 장애물 밀도 상한을 유지합니다.


## 파일

- `index.html`, `src/style.css`: 화면과 반응형 배치
- `src/engine.js`: 물리, 입력 상태, 코스, 충돌, 아이템, 점수
- `src/sky.js`: 하늘색 전환, 구름바다, 별빛, 행성과 성운
- `src/game.js`: Canvas 표현, 캐릭터 동작, 소리, 키보드·터치, 기록
- `assets/`: 승인된 캐릭터 그림과 생성·가공 출처
- `tests/engine.test.cjs`: 게임 규칙과 코스 검증
- `tests/pilot.cjs`: 검사용 좌우 조작 시뮬레이터. 게임에는 포함하지 않습니다.
- `scripts/build.cjs`: 독립 실행 HTML 생성
- `scripts/package-site.cjs`: 게임 사이트에 원본 파일과 썸네일 복사
- `scripts/verify-browser.cjs`: 브라우저 조작 검증
- `build/`: 실행 파일, 빌드 정보, 검증 결과와 화면 캡처

## 빌드와 검증

게임 자체는 외부 라이브러리를 사용하지 않습니다. 개발용 명령에는 Node.js가 필요합니다.

```sh
node --test tests/engine.test.cjs
node scripts/build.cjs
```

게임 사이트 배포본은 다음 명령으로 준비합니다. 사이트의 Git 저장소에는 실행에 필요한 파일, 수정 가능한 소스와 검사 스크립트를 함께 보관합니다. 빌드 결과와 개인 플레이 기록은 포함하지 않습니다.

```sh
node scripts/package-site.cjs ../My_web_games
```

게임 파일은 `games/star-munch/`, 썸네일은 `thumbs/star-munch.svg`에 들어갑니다. `games.json`에 등록한 뒤 사이트 저장소의 `main`에 반영하면 GitHub Pages에서 게시합니다.

브라우저 검사는 Playwright와 Chromium, 실행 중인 로컬 서버가 필요합니다.

```sh
node scripts/verify-browser.cjs
```

2026-10-13 확인 결과:

- 게임 규칙 검사 **30개 통과**. 16개 시드의 별 배치와 장애물 경로를 확인했고, 16개 실제 물리 시뮬레이션에서 좌우 입력만으로 1,800m까지 도달했습니다. 일반 도약 간격의 중앙값이 0.8초 이상인지도 검사합니다. 부스트 전후의 기존 별·장애물 유지, 직접 조작에 따른 수집 차이, 8개 시드의 5개 좌우 위치에서 기존 별로 복귀하는 흐름을 확인했습니다.
- Chromium 브라우저 검사 **94개 통과**. 실제 방향키 입력으로 분산된 다음 별까지 이동하고, 정점과 낙하를 거쳐 재도약하는 흐름을 확인했습니다. 별줄 옆을 지나가면 수집되지 않고, 직접 방향키로 진입하면 수집되는 것을 확인했습니다. 자연스럽게 얻은 부스트와 일반 별·장애물이 같은 화면에 이어지는 모습도 검사했습니다.
- 화면 양쪽의 위·중간·아래 터치, 한 손가락으로 방향 전환, 짧은 양손 겹침 방지, 양손 도약 중 방향 유지, 계속 누를 때 재발동 방지, 충전 표시로 직접 도약하는 동작을 검사했습니다. 충전 부족·부스트 중 입력을 나중에 실행하지 않는지와 손 떼기·취소·포인터 캡처 해제·일시정지·포커스 해제·재시작·회전 후 입력 해제도 확인했습니다.
- 큰 별의 3칸 충전, 8칸 상한, 충전 완료 알림과 실제 충전 게이지 표시, 큰 별로 완성한 충전으로 도약하는 흐름을 확인했습니다.
- 4가지 시드에서 좌우 입력만으로 12,000m까지 비행하고 충돌·보호막 소모 없이 우주에 도달했습니다. 100가지 시드에서 약 14,000m까지 총 78,581개 높이 구간을 생성해 오류가 없음을 확인했습니다.
- 배경 경계의 색·효과 연속성, 고도에 맞는 장애물 종류, 우주에서 보호막·부스트와 충돌 처리, PC·휴대폰 우주 화면과 모바일 양손 도약을 확인했습니다.
- 기록 저장, PC·휴대폰 세로·가로 배치, 오프라인 파일 실행도 검사했습니다.
- 브라우저 오류와 실패한 리소스 요청은 없었습니다.
- 휴대폰은 브라우저의 기기 모사로 검사했습니다. 실물 휴대폰과 Safari·Firefox에서의 확인은 아직 하지 않았습니다.
